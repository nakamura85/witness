# 美术规格 · 手绘漫画风（Valiant Hearts 参考）

> **目标风格**：参考《Valiant Hearts: The Great War》（育碧，2014）——手绘上色漫画风，粗墨描边、平涂色块、卡通高光、无模糊渐变、饱和度高但不刺眼。
> 所有美术由代码程序化绘制（`Node2D._Draw()` / `CanvasItem._Draw()`），**不依赖贴图/PNG 资产**，确保风格零漂移。

---

## 1. 统一风格入口：`InkStyle.cs`

所有美术代码**必须**通过 `InkStyle` 取色/描边。禁止硬编码 Color 值。

```csharp
InkStyle.InkColor      // 墨色描边（深棕近黑 RGB(36,26,20) ≈ #241a14）
InkStyle.InkSoft       // 次描边（浅色物体用，避免贴黑纸）
InkStyle.BoldStroke    // 主轮廓描边宽度 = 3.0px
InkStyle.Stroke        // 内部缝线描边 = 1.6px
InkStyle.ThinStroke    // 最细细节 = 0.9px
InkStyle.GroundShadow  // 接触阴影冷色半透明叠层
```

### 工具方法

```csharp
// 先描边再平涂多边形
InkStyle.PenStroke(canvas, poly, fillColor, outlineColor, bw = BoldStroke);

// 先描边再平涂矩形（木箱/沙袋/砖块）
InkStyle.InkRect(canvas, rect, fill, outline);

// 卡通高光：一个小圆点，画在物体左上受光角
InkStyle.KawaiiHighlight(canvas, litPoint, size, highlightColor);

// 卡通高光：一条短直线
InkStyle.KawaiiLineHighlight(canvas, from, to, highlightColor, width = 2f);

// 颜色调暗 / 调亮（硬一档，不插值渐变）
InkStyle.Shade(baseColor, k = 0.62f);
InkStyle.Lighten(baseColor, k = 1.18f);
```

## 3. 人物规格（FigureActor.cs）

### 比例
- **身高 140px**（从脚底到头顶）
- **头身比 1:6**：头 ~24px，身体 ~116px
- **站立重心**：脚踩地（y=0）→ 髋 y=-52 → 肩 y=-92 → 头 y=-128
- **蹲下时**：髋 y=-26 → 肩 y=-62 → 头 y=-94（整体压扁 ~40%）

### 头（圆形大头娃娃）
- 圆形头骨：半径 12px，平涂肤色 + `PenStroke` 墨描边
- **眼睛**：大圆形瞳孔（5px）+ 高光小白点（1.5px 右上）+ 白色眼白底
- **嘴唇**：两瓣平涂（上深下浅），嘴角有微笑弧度
- **脸颊**：冻红晕（东北军/冬季场景）椭圆平涂，半透明 60%
- **耳朵**：小半圆，平涂肤色

### 头饰
| 种类 | 画法 |
|------|------|
| 日军钢盔 | 半圆顶 + 前挑帽檐（+x 侧延伸）+ 盔顶脊高光 + 颌带 + 盔徽（小太阳）+ 粗墨描边 |
| 东北军布棉帽 | 三角帽顶 + 两侧护耳（-x 侧更大）+ 下颌系带 + 粗墨描边 |
| 平民头巾 | 额前褶 + 脑后结 + 布尾 + 粗墨描边 |

### 躯干
- 梯形（上宽下窄）：肩 24px → 髋 22px
- **平涂 Base + 背光侧硬边 Shadow 条 + 卡通高光小圆点**（上半部分受光角）
- **粗墨描边 3px**
- 下摆：垂坠布条（棉军装垂 18px，蹲下垂 12px），有风时微摆（hemSway）

### 四肢（卡通圆柱）
- **矩形外框 + 硬边阴影条 + 高光小圆点 + 粗墨描边**
- 禁止：Tube 渐变、高光带模糊
- 关节处：同色圆补缝 + 墨描边环

### 手 / 枪 / 脚
- 手：3px 圆，平涂肤色
- 枪：**粗墨描边 + 平涂木色枪托 + 平涂金属枪管** + 枪栓 + 准星
- 脚 / 靴子：6 边形（靴筒 + 前掌 + 后跟），平涂 + 墨描边

### 走路动画（流畅度关键）
```
Phase 推进速度：Speed / 90  →  Phase += delta * (Speed / 90)

每帧关节解算顺序：
1. 重心 hip.y += sin(phase*2) * 1.4 * stride       （脚落地时沉一点）
2. 肩肩 shoulder.x += sin(phase) * 2.0 * stride     （横向摇摆）
3. 前腿 footA = 支撑脚（落地）/ 摆动脚（抬起）
4. 后腿 footB 反向 180°
5. 双手 HandTarget 摆臂反向（肩膀摆多少，手臂反摆多少）
6. 下摆 hemSway += sin(phase*2.2) * 1.4
```

### 跳跃动画
- Gounded=false 时：髋 y=-47，双脚 tuck 收在身前
- 粗描边剪影感，不落半透明

### 接触阴影
- 压扁扁椭圆（X 方向宽 1.05 倍，Y 方向压 0.22）
- 颜色 `InkStyle.GroundShadow`（冷色半透明）
- 禁止模糊羽化；硬边

### 地面雪
- **3 档平涂**：亮雪顶（H 从地面到 -30px）→ 正常雪体（H -30 到 -10px）→ 雪地阴影底部 + 粗墨描边
- 地面轮廓：**手绘锯齿轮廓**（不是直线），有随机上下波动 ±3px
- 雪面点缀：随机散布**小石子**（粗墨描边椭圆平涂）+ **冰裂线**（细线）

Ink   层（最上）：航线箭头 + 进军路线 + 城镇图钉 + 纸条 + 章节栏 + 粗墨描边

## 6. 标题画面规格（TitleScreen.cs）

### 背景层（按绘制顺序）
```
1) 夜空 深紫蓝平涂 + 星星（随机 60 颗）
2) 远山剪影 大锯齿 + 深灰平涂 + 粗墨描边
3) 城墙（右侧主体） 粗墨描边矩形 + 雉堞（锯齿垛子）+ 城门洞（黑拱）
   - 城门洞内：温暖橘黄灯笼光（径向渐变，唯一场合允许渐变）
   - 城墙顶部：积雪帽（细白线）
4) 枯树（左侧前景） 主干 + 8 条枯枝 + 粗墨描边 + 冻霜（白细线覆盖）
5) 石碑（枯树旁） 竖长矩形 + 粗墨描边 + 顶部高光点
6) 地面 深棕平涂 + 粗墨描边 + 地面石子点缀
7) 飘雪层（前景动画） 30-50 颗白圆点，速度 0.5-2.0px/s，水平漂移 ±0.3px/s，随机大小 1-3px
8) 乌鸦（3 只，翅膀振翅动画）
```

### 按钮
- 手绘风：米黄平涂 + 粗墨描边 3px + 下边粗 4px 上边粗 2px（手绘压笔感）
- Hover：颜色加深；Pressed：上下粗度反转（按下感）
- 文字：墨色 + 淡黄色描边

## 7. 描边层级规范

| 层级 | 宽度 | 颜色 | 用在哪里 |
|------|------|------|----------|
| 主轮廓 | 3.0px | InkColor | 人物整体、道具整体、场景整体外框 |
| 次轮廓 | 1.6px | InkSoft | 躯干上的缝线、关节内缝、道具内部分隔线 |
| 最细细节 | 0.9px | InkSoft | 子弹轨迹、雪面裂纹、纸上字 |
| 内部高光 | 2px | InkColor 的 Lighten(1.05) | 高光短条的边缘（极少见，主要用纯色） |

## 8. 禁止清单

1. ❌ 禁止高斯模糊 / 渐变阴影（除了月亮光晕和灯笼光——这俩是氛围需要）
2. ❌ 禁止贴图 / PNG 资产（所有美术程序化绘制）
3. ❌ 禁止半透明渐变叠加（阴影块必须是不透明硬边色块）
4. ❌ 禁止字体反锯齿模糊（CanvasItem.Modulate 必须是纯色）
5. ❌ 禁止硬编码 Color 值（全部走 InkStyle）
6. ❌ 禁止 Tube() 渐变圆柱体（必须改成矩形外框 + 硬边阴影 + 高光）
