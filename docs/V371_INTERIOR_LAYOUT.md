# v3.71 室内布局重做 · 设计冻结（待确认）

> 依据用户 2026-11-12 室内四条诉求 + 关键物提示。本文件为阶段一策划冻结稿，
> 确认后（§5）才进入阶段二实现。所有数值为可复算的初值，实现时以本表为准。

## 1. 目标与边界

把室内从「平贴背景的 2D 物件」升级为「有纵深、可翻找的搜查空间」。

已确认方向（用户本轮三问应答）：
- **窗光 = 跟关卡全局时辰联动** → 新增 `WorldClock`，关卡加载时设定。
- **掉落 = 实时物理** → 重力 + 碰撞的自定义积分器，物件真实下落 / 回弹 / 静止。
- **陈列 = 混合** → 部分摆桌面可见、部分藏家具内、部分掉地上。

## 2. 子系统与设计

### 2.1 纵深与遮挡（诉求①：物件不要平贴背景）
新增 `Furniture` 模型：类型 `Desk / Cabinet / Stove / PictureFrame / Shelf`；
每类有锚点 `Rect2`、开启动画 `OpenT(0..1)`、藏匿的 `ContainsSpotId`。

绘制分层（后 → 前），全部走 `InkStyle` 漫画原语：
1. 背景贴图（不变）
2. 窗光 + 窗外晕染（新增，见 2.3）
3. **被家具遮挡的地落物**（先画，后被家具前脸盖住 → 部分不可见）
4. 家具主体（侧板 / 台面 / 正面，带描边与三档平涂 → 有体积感）
5. 台面陈列物（画在台面之上、前脸之下）
6. 容器内物（**仅容器开启时**画在凹洞里）
7. 家具前脸 / 掀开的盖（盖住未开容器 → 关闭时看不见里面的物）
8. 接触阴影（硬边压扁椭圆，`InkStyle.GroundShadow`）
9. 关键物微光（§2.5，画在物件之后）
10. 准星（第一视角）/ 小人（第三视角）
11. 提示牌 / 结果条 / 标题 / 操作提示（不变）

关键机制：**容器关闭时前脸画在藏匿物之上 → 看不见；开启时前脸让位 → 凹洞露出物件**。
这就是纵深，不再是平贴。

### 2.2 容器翻找（诉求②）
三类藏匿点（按 `RoomType` 播种，坐标见 §3 锚点表）：
- **桌抽屉** `Desk`：抽屉滑出动画，露出里面信件 / 弹药。
- **挂画后凹洞** `PictureFrame`：挂画翻起，墙后凹洞藏文件。
- **灶台内** `Stove`：灶门摆开，里面藏信 / 遗书。
- **柜内** `Cabinet`：柜门开，里面藏医药包 / 密电。

交互沿用第一视角：准星靠近家具按 `E` → 开启动画（`OpenT` 0→1）→ 露出凹洞物件 →
再按 `E` 搜查（复用原 `OnSpot` 搜刮 / 读信 / 撬箱逻辑）。

`Step()` 的「最近可交互」判定扩展为取最近于：
`{ 可见陈列物, 未开容器, 已开容器的露出物, 静止地落物 }`。

### 2.3 窗光随时辰（诉求③）
新增 `WorldClock`（静态类，无需 Autoload 节点）：

| Phase | 语义 | 窗外晕染 | 房间光晕 | 地面光束 |
|---|---|---|---|---|
| `Day` | 早上日光 | 浅蓝天 + 雪原剪影 | 暖柔白，弱 | 淡暖斜光多边形 |
| `Dusk` | 黄昏 | 橙红横带 + 低山 | 琥珀渐变（窗→内） | 橙斜光多边形 |
| `Night` | 夜晚月光 | 深蓝 + 月 + 星点 | 冷蓝，窗处最亮 | 淡冷蓝月光多边形 |

- 关卡加载时设定：`WorldClock.Time = Phase.Xxx`（具体映射见 §5）。
- 渲染：后墙画一扇带框窗户；窗外晕染 + 房间光晕都按 `Phase` 取色（取自 `WorldClock` 调色板）。
- **诚实边界**：窗外是「按时辰的风格化晕染」，**不是**实时渲染的运行关卡场景（后者超出本轮范围）。

### 2.4 实时掉落物理（诉求④）
`DropItem`（属于 `FloorDrop` 模式的 `RoomItem`）：
- 触发：进屋时（或「来不及藏」脚本触发）从抬高 `y0` + 向下初速 `v0` 开始。
- 积分（`_Process`，单位：像素 / 秒）：
  - `vel.y += G * dt`，`G = 1400`
  - `pos.y += vel.y * dt`
  - 地板碰撞：`pos.y >= FloorY` → `pos.y = FloorY; vel.y = -vel.y * 0.35`（回弹衰减）；`|vel.y| < 40` 且贴地 → `Settled = true`
  - 家具顶碰撞：若 `x` 落在某家具 `Rect` 的 x 区间且下落穿过台面 `topY` → 停在 `topY`（落上台面）；若撞侧边 → 滑到最近空位
- 接触阴影随离地高度缩放（高 → 大；按 `InkStyle` 仍硬边只缩放大小）。
- 静止且 `x` 落在某家具 `Rect` 内且 `y` 低于台面 → 在家具前脸**之前**画 → 部分被遮挡。
- 确定性：`StrHash(seed)` 定初速 / 落点，便于复现；运动本身实时。
- Capture 时先跑「静止 pass」（迭代到 `Settled`）再截帧，证明物理已发生且帧可复现。

### 2.5 关键物微光（提示）
`RoomItem.Key = true` 的物件（建议清单见 §5）未搜前画脉冲光晕：
- `alpha = 0.10 + 0.06 * sin(t * 3.2)`，暖纸色 `PaperLit`
- 画在物件**之后** → 似有微光但不刺眼；搜过后 `Done` 即熄灭。
- 振幅刻意压低（`0.06`），不抢眼。
