# 桥贴图风格迁移管线（v3.26）

`assets/art/props/bridge.png` 原本是一张 **写实 3D 渲染**（1530×812，1.67MB）。
整关卡是手绘上色漫画风（墨线 + 水彩平涂 + 留白），
这张写实图放进雪原里像"另一个游戏贴进去的"。

这个目录是把它转成手绘风的那条管线。

## 用法

```bash
pip install "numpy>=1.22" "pillow>=12.3.0"

python restyle_bridge.py \
    bridge_PHOTOREAL_ORIGINAL.png \
    ../../assets/art/props/bridge.png \
    1.0            # 墨线强度
```

Godot 侧需要重新导入才会生效：

```bash
Godot_v4.7.2-stable_mono_win64.exe --headless --import --path .
```

## 做了什么

| 步骤 | 说明 |
|------|------|
| 0.0 拆检修走道栏杆 | 栏杆每一格都是 < 400px 的封闭孔洞，会被下一步填成实心，糊成一条压在轨道上方的蓝灰实心板（"一个桥出现两条路"的另一半根因）。用三条几何判据把它拆掉：构件**厚度**（距离变换）、**上方有无桁架延续**、**长横杆** |
| 0.1 填缀条小孔洞 | 只填 < 400px 的（缀条格构）；≥ 400px 的留着（主桁架大透空是桁架该有的通透感） |
| 0.2 双通道降采样 | 细节层定墨线位置，色块层（降采样 x6 + 开运算）取平涂色，铆钉 / 节点板 / 腹杆自动消失。**必须预乘 alpha**，否则透明区残留的黑会混进灰度 |
| 1 材质分区 | 钢 / 混凝土 / 木 / 锈 / 雪，桁架区一律不给雪（现实里雪积在水平面上，不会挂在斜杆上） |
| 2 墨线 | 轮廓线**向内收缩**（`alpha - MinFilter(alpha)`）而不是向外膨胀，否则会画到透明区变成满屏芝麻点；再乘 alpha 掩膜保证不出构件 |
| 3 平涂 | 三档（base / shadow / highlight），跟 `scripts/InkStyle.cs` 的色板对齐 |
| 4 水彩 | 低频色相漂移 + 颜料沉淀 + 纸纹颗粒 |
| 5 色温对齐 | 实机取色：场景 RGB(113,118,120)、士兵 RGB(134,137,138)，桥去蓝提亮一档 |

## 注意

- **alpha 轮廓和几何一个像素都不动**，只改颜色。
- 栏杆的判定依赖"厚度"和"上方延续"，改贴图分辨率时要重新量 `deck_top_profile()` 里的线性拟合系数。
