## 一、士兵身高核查（你最担心的「特别突出」日军）

**结论：没有任何士兵比玩家高，不存在「姚明型」异常。** 所谓「突出」是**站姿士兵 vs 匍匐士兵的视觉落差 + 截图顶边裁切**，不是模型过高。

### 证据（来自代码常量，非肉眼猜测）

| 来源 | 立绘基准高 | 缩放 | 实渲染高 |
|---|---|---|---|
| 玩家（东北军）`FieldPlayer` | 108px | ×1.06 | **114.5px** (`PersonH`) |
| 日军敌人 近排 lane=+48 | 108px | ×1.06×1.00 | 114.5px（=玩家） |
| 日军敌人 中排 lane=0 | 108px | ×1.06×0.92 | 105.3px |
| 日军敌人 远排 lane=−48 | 108px | ×1.06×0.82 | 93.9px |
| 巡逻兵（日军）`Patrol` | 108px | ×1.00（无缩放） | 108px（比玩家还小） |

- `SpriteActor.Kind.Soldier`(日军) 与 `Kind.NortheastArmy`(我方) 基准高**都是 108px** → 双方身高统一。
- `EnemyScaleForLane` 缩放**永远 ≤ 1.06**，最大就是玩家高度，绝不会超过。
- v54c 里「巨大」的那位是**站姿**日军（114.5px，与玩家同高），旁边是**匍匐/爬行**士兵（换用 `soldier_na_prone` 贴图，躺平后屏幕高度天然只有约 1/3）→ 看起来 3–4 倍高，实则等高。另有可能被截图**顶边裁掉上半身**造成「无头巨人」错觉。
- 你定的锚点（亚洲男性 160–180cm、统一）在游戏里=所有站姿士兵 108–114.5px（±3%），已满足。

**未改动代码**：若强行改士兵缩放会破坏你 v3.25 已认可的「三排景深不同大小」规则（那是为解决「三人同高=景深塌掉」而做的）。如需让站/匍落差不那么刺眼，可选（非必须）：
- 方案 A：近排敌人缩放从 1.00 降到 0.94；
- 方案 B：避免站姿敌人与匍匐士兵紧邻出生。

## 二、桥贴图重描（v54b 桁架 + v54c 桥面区域）

`bridge.png` 是江桥**唯一**的光栅底图（代码里的 `Truss()` 只是缺图时的 fallback）。重写工具
`tools/bridge_restyle/restyle_bridge_ink.py`，把写实数字绘桥转成 **InkStyle 钢笔线稿+平涂水彩**。

### 关键修复（之前为什么「差很远」）
- 旧重描用 HSV 去饱和 → 桥变成**冷灰色**（与暖灰房子/士兵冲突）。
- 这次改为**暖色阶梯映射**（深暖棕→雪光暖灰），对齐 `house_intact_near` 的暖灰基调。
- 描边色严格用 `InkStyle.InkColor = (0.14,0.10,0.08)` 深暖棕；剪影做高斯抗锯齿，去掉撕裂边。

### 客观调色板对照（不看感觉，看分布）

| 资产 | 中位饱和度 | 中位明度 | 暖？ |
|---|---|---|---|
| 房子（你已认可） | 0.102 | 0.522 | 是 R≥G≥B |
| 士兵尸体（已认可） | 0.459 | 0.471 | 是（橄榄/卡其） |
| **新桥 h1（已提交）** | **0.194** | **0.506** | **是** |
| 旧桥（备份） | 0.082 | 0.353 | 偏冷灰 |

→ 新桥从「冷灰」回到「暖灰/棕」，明度也贴近房子，风格一致。

### 已提交
- `assets/art/props/bridge.png` = **h1**（5 色阶、暖灰、深棕描边、结构清晰，最均衡）。
- 备份：`tools/bridge_restyle/_old_bridge_backup.png`（原图，852KB，可随时回滚）。
- 候选备用：`_cand_h2.png`（更通透轻盈）、`_cand_h3.png`（墨线更密，偏重）。
