# 桥贴图风格迁移管线（v3.28）

`assets/art/props/bridge.png` 原本是一张 **写实 3D 渲染**（1530×812，1.67MB）。
整关卡是手绘上色漫画风（墨线 + 水彩平涂 + 留白），
这张写实图放进雪原里像"另一个游戏贴进去的"。

这个目录是把它转成手绘风的那条管线。**单文件、无外部依赖**（除 numpy / pillow）。

## 用法

```bash
pip install "numpy>=1.22" "pillow>=12.3.0"

python restyle_bridge.py \
    bridge_PHOTOREAL_ORIGINAL.png \
    ../../assets/art/props/bridge.png
```

Godot 侧需要重新导入才会生效：

```bash
Godot_v4.7.2-stable_mono_win64.exe --headless --import --path .
```

## 核心思路：把写实渲染当**线稿来源**，不当颜色来源

v3.26 那版是"给写实图换色"，结果做出来是一块蓝灰色的板。数据说明为什么：

| 指标 | 房子（参照） | 树（参照） | v3.26 成品 |
|------|------------|-----------|-----------|
| 墨线占比 | 12.1% | 11.1% | **2.3%** ← 只有色块，没有线 |
| 墨线颜色 | 近黑 (0.096,0.095,0.090) | 近黑 | **暖褐 (0.188,0.152,0.134)** |
| 留白（纸底） | 16.9% | 38.0% | **10.5%** |
| 平涂占比 | 56.3% | — | **77.8%** |
| 彩度 p50 | 0.035 | 0.016 | **0.090** ← 太艳，明显不是同一个游戏 |

而且它犯了一个**几何错误**：为了抹掉铆钉噪点，把桁架的镂空网格也填成了实心。
行扫描对比（row 120，x<700 段）：

```
原图    16 段构件，段段之间有缝（最宽 65px）
v3.26   4 段，其中一段 452px 连成一片
```

眼睛里这就是"一座实心的蓝灰帐篷"，根本不是钢桁架。

v3.27 换了做法：**几何一个像素都不填**（除了拆栏杆和补 1-2px 的针孔），
颜色按**材质**分而不是按亮度一刀切，墨线靠**局部对比 + 走向长度**提取。

## v3.28：为什么桥还是"太浅"

v3.27 把画风修对了，但桥在实机里还是**化在雪原里**。原因不是审美，是对比度：

| | 中位亮度 | p90 | 暖度 (R−B) |
|---|---|---|---|
| 雪山背景 `mountains.png` | **0.845** | 0.984 | −0.004（冷白）|
| 房子 | 0.493 | 0.956 | +0.063 |
| 榆树 | **0.309** | 0.804 | −0.008 |
| 烧毁房子 | 0.226 | 0.604 | 0.000 |
| 尸体（仰） | 0.250 | 0.470 | −0.008 |
| **v3.27 桁架** | 0.431 | **0.717** | −0.012 |
| **v3.28 桁架** | **0.342** | 0.514 | +0.027 |

两条硬约束从这张表里出来：

1. **前景实体都在 0.25~0.35**（榆树 0.309、烧毁房子 0.226、尸体 0.250）。
   桁架原来 0.431，最亮的 10% 更是冲到 0.717——贴着雪山的 0.845，
   整座桥的剪影就没了。对齐到 0.38 的曝光目标后，成品中位落在 0.342。
2. **色相必须中性**。背景是冷白，任何冷蓝灰的钢构都会跟背景同色。
   腹杆从"暗板岩蓝"改成**中性深灰**；锈褐主梁也把彩度收掉一档。

## v3.28：桥墩为什么改成"解析模型"

照片里墩面的明暗是**污渍、水渍和阴影**，不是结构。三条路都试过：

| 做法 | 结果 |
|---|---|
| 按原图亮度分档 | 迷彩色斑——柔和的渐变被硬边切成几块污渍形状的色块 |
| 逐列均值 → 竖向明暗带 | 条形码——逐列统计天生会把斜的东西拍平，墩面两根斜撑被展平成两条竖条 |
| 二维大模糊 | 还是色斑，只是更糊 |

第四条路：**不看原图明暗，用模型画**。墩子的位置靠 alpha 找（按列统计实体像素、
切连续段），形状靠模型画——光从右上来（全关卡的影子都朝左下），左暗右亮，
底边沉进河冰转暗。手绘的混凝土墩本来就是**几块大面**，不是一排等宽的竖条。

## v3.28：X 形钢架的镂空是**烘焙**进 alpha 的

西端桥墩是**两片混凝土夹一个 X 形钢桁架**，格子后面本该透过去看到雪山。
但写实渲染把天空烘焙进了贴图——那一带 alpha 完全不透明，镂空就这么没了，
墩子成了一整块灰板子。

天空像素好认：又亮、又冷、又几乎没有彩度。掩膜实测正好落在交叉钢架的
菱形格子里，钢构一点没伤到（3919 px）。抠掉之后 X 形自己透空了，
边缘的轮廓墨线自动勾出来。

## 做了什么

| 步骤 | 说明 |
|------|------|
| 0.0 拆检修走道栏杆 | 栏杆每一格都是封闭孔洞，会被填孔步骤填成实心，糊成一条压在轨道上方的板（"一个桥出现两条路"的另一半根因）。用三条几何判据拆掉：构件**厚度**（距离变换）、**上方有无桁架延续**、**长横杆** |
| 0.1 补铆钉针孔 | 按**内切圆半径**分级：半径 ≤1px 的针孔补掉；半径 ≤2px 的铆钉孔**保留几何但抹掉它的墨线环**。用开运算判"小孔"是错的——会把三角形桁架格子也吃掉（row 120 从 16 段塌成 7 段） |
| 0.2 抠烘焙天空 | 西端墩 X 形钢架的镂空。见上 |
| 1 墨线：局部对比 | 比邻域中位暗 0.10 以上才算线，只抓"缝"，不会把大片背光阴影当线 |
| 2 墨线：走向长度 | 铆钉是**圆点**（横竖走向都短），缝是**长线**（走向 ≥14px）。按走向长度一筛，噪点自然消失 |
| 3 墨线：手绘抖动 | 准备 9 条候选轮廓带（收缩/原位/膨胀 1px × 1/2/3px 宽），用低频噪声图挑。线于是有"落笔轻重"和"往外飘一点再回来"——照片的 alpha 边缘给不了的 |
| 4 平涂：材质分区 | **锈褐主梁**（照片里的钢构本来就是暖褐的）/ **中性深灰腹杆** / **中性钢桥面** / **暖灰混凝土** / **纸白雪**。v3.26 给它染成蓝灰，是"不像同一个游戏"的主因 |
| 5 平涂：硬边分档 | 分档之后不再做高斯软过渡，色块边界干脆，才像"画"出来的 |
| 6 平涂：曝光归一 | 写实渲染的曝光跟手绘色板不是一回事。照片里桁架中位亮度只有 0.30 出头，直接分档会得到一堵黑墙——按区把中位亮度对齐到色板该有的位置（桁架 0.38 / 桥墩不用这一套，见上） |
| 7 平涂：桥墩解析建模 | 见上 |
| 8 平涂：桥面结构分层 | 顶缘受光 / 梁腹 / 底缘阴影，按到桥面顶边的行距分层 |
| 9 雪 | 只给**极亮且几乎无彩**、且在构件**朝上边**的地方；桁架上**不铺雪**（照片级的雪是一小块一整块，贴在深色钢构上像一排白补丁） |

## 注意

- **桁架的镂空是桥的形状本身**，任何"填孔"操作都不能碰它。
- 栏杆的判定依赖"厚度"和"上方延续"，改贴图分辨率时要重新量 `deck_top_profile()` 里的线性拟合系数（当前 `y = 342 + 0.054x`）。
- 桥面顶边随透视是斜的，代码里 `deckRow = 355` 是**铁路线所在的那一行**，桥面梁体在它下面。
- **在孤立的贴图上判断画风会跑偏**。桁架镂空"看起来被填实"其实是裁图时把透明区合成到了黑底。
  判断画风要看实机同框截图——桥 + 房子 + 士兵 + 雪山一起。
