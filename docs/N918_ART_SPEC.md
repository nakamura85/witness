# 九一八事变关卡 · 美术风格一致性规格

> **版本**：v1.0（九一八方向包 / 资产规格）
> **基准关卡**：嫩江江桥（`v2.2`–`v2.4`，1931.11.4 深冬雪原）
> **性质**：非破坏性规格，**不修改任何代码**，仅定义资产复用与最小新增的美术规则。
> **一句话定位**：九一八 = 江桥同款 `InkStyle` 管线 + 同款资产族，**禁止任何新画风**。

---

## 0. 风格基准声明（最高优先级）

九一八事变（1931.9.18 初秋）与嫩江江桥（1931.11.4 深冬）是同一游戏的相邻关卡，必须由**同一支笔**画出。本规格强制以下三条铁律：

1. **唯一风格入口不变**：全部程序化绘制继续走 `scripts/InkStyle.cs`，沿用其全部常量（墨色描边、三档平涂色板、`PenStroke` / `InkRect` 工具方法）。九一八**不得新增描边规则、不得新增色板族**（极个别设备材质如需新增，必须在本规格 §4 登记并经美术总监批准）。
2. **混合管线不变**：沿用江桥已建立的「程序化手绘层（`Node2D._Draw()`）+ AI 图生图贴图层（同款水彩漫画画风）」混合管线。贴图层与程序化层共用同一坐标系、同一 `InkStyle` 取色，保证整画风格统一。
3. **资产血缘不变**：九一八任何新增贴图，都必须以江桥某张同管线资产为**图生图底图**重绘，视觉血缘与江桥同源；季节差异只通过**调色 / 覆盖层 / 粒子强度 / 资产选型**表达，绝不引入第二种画风。

> **与旧 `docs/ART_SPEC.md` 的关系说明**：旧文档 §8 写有「❌ 禁止贴图 / PNG 资产（所有美术程序化绘制）」，该条款属于江桥 `v2.2` 之前的纯程序化阶段。江桥自 `v2.2` 起已采用混合管线（图生图史实军服立绘 + 视差背景贴图 + 战场物件贴图，统一水彩漫画画风），`v2.3`/`v2.4` 持续重绘。本九一八规格遵循**当前江桥的现实管线（`v2.2`–`v2.4`）**，与旧条款中过时的「禁止 PNG」一句以本规格为准。两者在 `InkStyle` 唯一入口、3px 墨描边、三档平涂、无插值渐变等核心规则上完全一致。

## 1. 风格基准：唯一入口 `InkStyle.cs`（必须 100% 沿用）

九一八所有程序化绘制（地形细节、UI / 菜单、飘雪 / 暗角等特效、尸体血迹、屋内物件）**必须**从 `InkStyle` 取色与描边，禁止硬编码 `Color`。

### 1.1 描边与阴影常量（原样沿用，不重定义）
| 名称 | 值 | 用途 |
|------|-----|------|
| `InkStyle.InkColor` | 深棕近黑 `RGB(36,26,20)` ≈ `#241a14` | 主轮廓 3px |
| `InkStyle.InkSoft` | `RGB(71,56,46)` ≈ `#47382e` | 浅色物体 / 内部次描边 |
| `InkStyle.BoldStroke` | `3.0px` | 主轮廓 |
| `InkStyle.Stroke` | `1.6px` | 内部缝线 / 折痕 |
| `InkStyle.ThinStroke` | `0.9px` | 最细细节 |
| `InkStyle.GroundShadow` | 冷色半透明 `(0.10,0.12,0.14,0.38)` | 接触阴影（全场统一走 `SnowShadow.cs`） |

### 1.2 必须复用的色板族（九一八直接引用，不重新定义）
- **人物**：`NACoat`/`NACoatShadow`/`NACoatHighlight`（东北军灰蓝棉服）、`NACap`/`NACapShadow`（护耳棉帽）、`JPCoat`/`JPCoatShadow`/`JPCoatHighlight`（关东军卡其）、`JHelmet` 同族（钢盔 / 金属）、`Skin` 同族、`CivilianCoat` 同族（平民棉袍）。
- **民居 / 场景**：`AdobeWall`/`AdobeWallShadow`（夯土墙）、`PlankRoof`/`PlankRoofShadow`（木板瓦屋顶）、`WindowGlow`（窗暖光）、`Chimney`（砖）。
- **自然 / 道具**：`Snow`/`SnowShadow`、`Wood`/`WoodShadow`/`WoodHighlight`、`Sand`/`SandShadow`、`SackBase`/`SackVariation`/`SackShadow`（沙袋帆布）、`Night`（星空夜）。
- **辅助方法**：`PenStroke()`（描边+平涂多边形）、`InkRect()`（描边+平涂矩形）、`KawaiiHighlight()`（小圆点高光）、`KawaiiLineHighlight()`（短直线高光）、`Shade()` / `Lighten()`（硬调暗/调亮，不插值渐变）。

> 江桥程序化绘制代码（如 `FigureActor.cs`、`EnterableHouse.cs`、`CorpseActor.cs`）已直接引用上述常量，九一八复用同一批脚本逻辑即可，无需改动取色。

## 3. 九一八相对江桥的视觉差异清单（季节 / 色温 / 粒子 / 覆盖层）

> 核心原则：**差异只来自调色、覆盖层、粒子强度、资产选型，绝不来自新描边规则或新画风**。下表每条都给出「不改画风下的实现方式」。

| # | 差异项 | 江桥现状（深冬） | 九一八目标（初秋） | 不改画风下的实现方式 |
|---|--------|------------------|--------------------|----------------------|
| 3.1 | 雪覆盖量 | 满雪原、地面全白、屋顶厚雪 | 初雪薄覆 / 初秋微雪，地面露土露草 | 程序化地面雪层调薄（减少 `Snow` 平涂面积）；多用 `grass.png`（本就是雪地枯草）；屋顶雪线以覆盖层淡化 |
| 3.2 | 枯草 vs 雪白 | 枯草多被雪压 | 强调枯草黄、柳丛绿黄 | 直接复用 `grass.png` / `willow.png` 主体；不强行加雪盖 |
| 3.3 | 天空色温 | 冷蓝紫夜空 `Night` | 初秋夜偏暖一点的深蓝紫；或暖白昼光 | 仍走 `InkStyle.Night` 同族，用 `Lighten` 微调色温，**不引入新色板**；白天场景加暖白天光叠层 |
| 3.4 | 飘雪粒子 | 强飘雪（30–50 颗白点） | 关闭或极少量（可改飘落叶/微雪） | 减弱 `SnowShadow`/飘雪粒子数量与速度；粒子仍为硬边小圆点平涂，与江桥同风格，只是数量级不同 |

## 5. 无线电发信机（屋内 spot）美术规格

**承载方式**：作为 `EnterableHouse` 屋内 UI 的可交互物件（按 E 互动，触发情报/剧情），复用江桥屋内系统（同一 `house_interior` 背景、`door_leaf` 门扇、`SoftSnow` 落地阴影、`SnowShadow` 接触阴影）。

### 5.1 视觉描述
- **民国式无线电发信机**：木质机箱（正面板带若干旋钮、圆形表头/度盘、玻璃电子管），呈「箱式电台」轮廓。
- **手摇发电机**：木质飞轮 + 曲柄，置于电台一侧，体现「无电网、手摇供电」。
- **室外天线**：从窗口/屋顶拉出的简易天线——立杆 + 水平拉线（细墨线），暗示对外发报。
- 整体为「一台设备 + 一台发电机 + 一组天线」的屋内近景组合，占屋内一面墙的视角。

### 5.2 墨线描边（沿用 `InkStyle`）
- 主轮廓：`InkStyle.InkColor` + `BoldStroke` 3px（机身、发电机外框、天线立杆）。
- 内部缝线/分格（面板格栅、机箱木板缝）：`Stroke` 1.6px。
- 最细细节（旋钮刻度、表盘指针、天线拉线）：`ThinStroke` 0.9px。
- **禁止**任何柔和羽化或模糊描边。

### 5.3 平涂色板建议（优先复用现有 `InkStyle` 色板）
| 部件 | 建议色板（来自 `InkStyle`） | 说明 |
|------|------------------------------|------|
| 木质机箱 / 发电机飞轮 | `Wood` / `WoodShadow` / `WoodHighlight` | 与 `crate` / `telcrate` 同木色族 |
| 金属面板 / 天线立杆 | `JHelmet` / `JHelmetShadow` / `JHelmetHighlight` | 钢灰冷色，与江桥钢盔/钢梁同源 |
| 电子管玻璃 / 指示灯 | `WindowGlow`（窗暖光） + `Lighten` | 暖光点缀，呼应屋内窗光 |
| 旋钮 / 表盘外壳 | `Chimney`（砖灰）或 `InkSoft` | 小件深色 |
| 导线 / 天线拉线 | `InkSoft` 细线平涂 | 非渐变 |
| 接触阴影 | `GroundShadow`（统一走 `SnowShadow.cs`） | 与屋内其他物件、玩家影子同源 |

> 如需新增一个「暗铁/发电机铸铁」色（现有色板无纯铸铁），**必须**在 §4 登记为最小新增并审批；优先先用 `JHelmetShadow` 或 `JPCoatShadow` 替代，避免新增。

### 5.4 与屋内其他物件风格统一要点
- 同为 **3px 墨描边 + 三档平涂硬色块 + 无插值渐变**，与 `door_leaf`、箱内物资、屋内角落阴影同一语言。
- 高光用 `KawaiiHighlight` 小圆点打在设备**左上受光角**，与江桥全线卡通高光一致；**不引入模糊光晕**。
- 若需表现「通电指示灯微光」，仅可复制 `telcrate` 已使用的「暖灯光晕」特例，且色温/画法须与 `telcrate` 一致（不得自创第二种光效）。
- 落地阴影与接触阴影接入 `SnowShadow.cs` 同一套（色调/日光方位/昼夜强弱），不出现独立浮动椭圆或双重影子。

## 6. 角色：九一八东北军 / 日军立绘是否重新生成？

**结论：直接复用江桥的 1931 军服立绘，不重新生成。**

理由：
1. **时代与制式一致**：九一八（1931.9.18）与江桥（1931.11.4）仅相隔约 7 周，东北军 1931 灰蓝护耳棉帽青天白日帽徽、日军昭五式大檐帽黄星三八式步枪在两套场景中是**同一批制式、同一画师（同一图生图管线）**产出的立绘，无重画必要。
2. **避免双画风风险**：重画必然引入笔触/色温漂移，违背「同一支笔」铁律。
3. **复用清单（§2.1 已列）**：`soldier_na.jpg` / `_aim` / `_crouch` / `_prone` / `_corpse`、`soldier_ija.jpg` / `_corpse`、`corpse_na/ija_prone/supine.png` —— 九一八**原文件名直接调用**，不新生成任何角色立绘。

> 若后续叙事需要在九一八出现「中央军 / 八路军」等江桥没有的军服，才走 §4 的新增流程，且仍以江桥军服立绘为底图图生图。

## 7. 一致性验收清单（QA / 美术自检）

逐项核对「九一八是否与江桥画风一致」：

- [ ] **描边宽度**：所有九一八资产主轮廓均为 `BoldStroke` 3px（`InkColor` 深棕近黑 `#241a14`）；内部 `Stroke` 1.6px、细节 `ThinStroke` 0.9px。图生图贴图的墨线肉眼/像素比对与江桥同资产一致。
- [ ] **色板来源**：九一八所有颜色取自 `InkStyle` 常量（`NACoat`/`JPCoat`/`AdobeWall`/`Snow`/`Wood`/`Night` 等），无硬编码新 `Color`；如有登记的最小新增色，已在本规格 §4 审批。
- [ ] **平涂三档**：每块物体 `base → shadow → highlight` 硬色块，**无插值渐变**（除月亮/灯笼光晕特例，且该特例仅存在于江桥既有氛围层）。
- [ ] **卡通高光**：高光为 `KawaiiHighlight` 小圆点 / `KawaiiLineHighlight` 短直线，无模糊光晕。
- [ ] **贴图层合成方式**：九一八图生图资产与江桥 `sprites/`、`backdrop/`、`props/` 同源（同一水彩漫画画风管线：去白底抠图 + 紧裁 + 同款墨线），与程序化层共用同一坐标系、同一 `InkStyle` 取色。
- [ ] **粒子风格**：飘雪/落叶为硬边小圆点平涂（无高斯模糊），与江桥 `SnowShadow`/飘雪一致；九一八仅按 §3 减弱数量级，不换画法。
- [ ] **接触阴影**：全部走 `SnowShadow.cs` 同一套（色调 / 日光方位 / 昼夜强弱），无「双重影子」或独立浮动椭圆。
- [ ] **资产血缘**：九一八新增资产（§4）均以江桥某资产为底图图生图（`rail_blast←bridge/crater`、`beidaying←village/house`、`radio_station←house_intact`、`radio_set←telcrate`），视觉血缘同一。
- [ ] **季节差异实现**：九一八与江桥的差异仅来自调色覆盖层 / 天空色温 / 粒子强度 / 资产选型（§3），无新增描边规则或新画风。
- [ ] **角色立绘**：九一八直接复用 `soldier_na*` / `soldier_ija*` / `corpse_*` 原文件，像素级与江桥相同。
- [ ] **屋内物件**：无线电发信机（§5）与 `door_leaf` / 屋内物资共用 3px 墨线、三档平涂、卡通高光、同一 `SnowShadow` 接触阴影。

---

## 结语

**只要严格走 `InkStyle` + 图生图同款画风，两关视觉就是同一支笔画出。**

### v2.2 决策 D1 史料依据（必须写进文档）

**亲历者史料（历史事实）**：
- 1931.9.18 沈阳当日：「天气晴朗，没有风，中国北方秋季里的好天气」。
- 事变夜 22:20 柳条湖铁路爆破、枪声彻夜；是**初秋清朗凉夜**。
- 当天为**星期五**。

**沈阳 9 月气候常态**：
- 月均高温 23.7℃ / 月均低温 13.5℃；
- **无降雪**；约 64% 概率为晴到少云；微风、干燥。

→ 结论：九一八美术方案**删除全部雪相关元素**（见 §v2.3），改用初秋暖色与清朗夜；季节真实度以史料为准，推翻 v1「初秋微雪」。

### v2.3 D1 衍生：删除 / 替换的雪相关元素

**删除（v1 中需剔除的雪感）**：
- ❌ `SnowPuff` 飘雪粒子 —— 全部移除，改为初秋**微风 + 偶尔落叶**（落叶仍走硬边小圆点平涂，与江桥同风格，仅换素材）。
- ❌ 积雪地 / 地面全白 —— 地面以 `grass.png` 枯草黄为主，露土露草，无雪白覆盖。
- ❌ 深冬冷蓝紫色温 —— 改用初秋暖色天光（§v2.4）。
- ❌ `SnowShadow` 的「雪感」—— 接触阴影机制（`SnowShadow.cs`）仍作为统一接触阴影系统沿用（不修改代码），但其语义由「深冬雪原阴影」改为「初秋清朗夜阴影」，不再带雪景冷调雪感；阴影色调走初秋暖调。

**保留（铁律不变）**：
- ✅ `InkStyle` 唯一入口、3px 墨描边、三档平涂、无插值渐变。
- ✅ 混合管线（程序化层 + 图生图贴图层）。
- ✅ 资产血缘（新增资产仍以江桥同管线资产为底图图生图）。
