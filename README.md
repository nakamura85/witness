# 见证者（Witness）· 二战亚洲战场手绘漫画风叙事游戏

> 二战的历史不是从 1937 年才开始的。要还原事实，就得从源头讲起——1895 年的马关条约、1910 年的日韩合并条约，殖民如何一步步吞下朝鲜半岛与台湾地区，直到 1931 年九一八、1937 年的南京。

一款 **2D 叙事严肃游戏**（Godot 4.7.2 .NET / C#）。

## 美术风格

**手绘上色漫画风（Hand-drawn cel-shading manga）** —— 粗墨描边、平涂色块、卡通高光，参考《勇敢的心：世界大战》的手绘质感。游戏采用**混合美术管线**，贴图层与程序化绘制共用同一坐标系，保证整画风格统一：

- **程序化手绘层（纯 `Node2D._Draw()`）**：UI / 菜单 / 暴风雪·飘雪·灯笼光晕·暗角等特效、尸体与血迹、地形细节（沙袋、桥墩、桁架、弹坑、铁轨、碉堡），风格统一入口为 `scripts/InkStyle.cs`（墨色描边 `InkColor` + 平涂色板 + `PenStroke` 工具方法）。
- **AI 生成贴图层（图生图，保持同款水彩漫画画风）**：
  - **史实军服角色立绘**（`assets/art/sprites/`）：东北军 1931 灰蓝棉服护耳棉帽青天白日帽徽、日军昭五式大檐帽黄星三八式步枪；含立姿 / 据枪 / 蹲 / 匍匐专姿（`soldier_na_aim` / `_crouch` / `_prone`）、**阵亡尸体**（`corpse_na/ija_prone/supine` 俯卧 / 仰卧）、NPC / 难民 / 建筑 / 道具。
  - **视差背景贴图**（`assets/art/backdrop/`，layer by layer 厚度 / 纵深感）：雪山 `mountains`、东北民居村落（战后残破）`village_ruined`、榆树 `tree_elm`、白桦 `tree_birch`、柳丛 `willow`、雪地枯草 `grass`，以 `DrawTextureRect` + `DrawSetTransform` 合成进 Far / Mid / Near / Fore 四层视差。初秋支线另含 `*_autumn` 系列（枯黄草坡 / 暖橙远山 / 残叶榆树 / 惨白月亮）。
  - **战场物件贴图**（`assets/art/props/`）：沙袋掩体堆 `sandbags`、弹药木箱 `crate`、可进入的残破 / 焚毁近景民居 `house_ruined_near` / `house_burned_near`、含桥墩桁架的江桥 `bridge`、电台小屋 `radio_station`，与角色 / 背景同一管线出图。
- **图层**：4 层视差（Far 0.06 / Mid 0.24 / Near 0.55 / Fore 1.32；ZIndex Far -40 / Mid -30 / Near -20 / Player 0 / Enemy 2 / Fore 5）。贴图层与程序化层叠加产生厚度与纵深。
- **室内程序化钢笔淡彩层（v3.64 新增）**：`HouseInteriorUi.RoomBg` 用 `WashPaint` 画纸本底、柔边水彩罩染、断续排线墨线、纸纹与水痕，与关卡贴图层共用冷灰低饱和色系；通信据点按史实电台操作动线布置器材。仍是程序化绘制，质感与 AI 生成贴图有差距。

## 游戏流程

> 按历史时间线推进：**先 1931.9 九一八事变，再 1931.11 嫩江江桥**。东亚大地图会随进度把“当前章节”红图钉自动推进到对应地点。

1. **内容警告** → **标题画面**（`assets/art/title.jpg` 古城墙雪景照片全屏铺底 + 程序化叠层：飘雪粒子 + 灯笼暖光晕 + 暗角 vignette，手绘漫画风菜单）
2. **东亚大地图**（手绘漫画风时间线 Hub：朝鲜半岛 & 台湾地区的殖民标记、1895–1945 日军进军路线、档案纸条；读完源头两张纸条后路线显影，进入按钮按当前章节点亮）。**v3.64 起为两段式**：第一章路线只显影到沈阳 · 九一八事变，江桥地名 / 图钉 / 北上路线不提前出现；九一八通关返回地图后，红图钉才从沈阳沿铁路北上迈向嫩江江桥，行军标记到位后才解锁江桥关卡
3. **纸条档案**（《马关条约》《日韩合并条约》原文、殖民动机、历史代价）
4. **九一八事变 1931.9.18 关卡**（沈阳柳条湖初秋夜 · 可进入/可搜索的叙事场景，4 层视差初秋夜）
5. **嫩江江桥 1931.11.4 关卡**（手绘漫画风横版 2D 关卡，4 层视差雪原战场；九一八通关后地图自动推进到这里，且需等第二段行军标记抵达）
6. **记录证言**：东北军幸存者口述史料，走到位置按住 E 约 1.2 秒记录
7. **通关档案** → 史料馆

#### 修复了什么

- **沙包避让一直失效（本轮最关键的坑）**：`CoverArt` 在**构造函数阶段**就 `_game.AddChild` 入树并先落位，而 `BuildHouses()` 在 `_Ready()` 里才执行——行号上 `BuildHouses()`(274) < `_coverArt`(933) 是假象，两者根本不在同一个方法里。对象初始化器里 `DoorXs = _houses.Select(...)` 求值永远是空数组，且 Godot 子节点 `_Ready()` 先于父节点，连「注入后重算」都救不了。最终把**注入 + `RebuildLayout()` 挪到 `_Ready()` 的 `BuildHouses()` 之后**才真正生效。靠临时 `GD.Print` 打 `[ADDHOUSE]` / `[BUILDHOUSES]` / `[INJECT]` 看日志先后定性。
- **Godot 4 C# 绘图 API**：`DrawColoredPolygon(Vector2[], Color)` 只收单色，逐顶点颜色必须用 `DrawPolygon(Vector2[], Color[])`（编译报 CS1503 已修）。
- **`triangulation failed`**：`SoftWash` 的边缘抖动固定 ±1.6px，在 16×14 小物件上相邻采样点仅 3px 导致轮廓自交；改为随尺寸缩放 `min(3.2, min(w,h)/10)`，`CaptureRoom` 已归零（两关各剩 1 次前景雪檐的历史无害警告）。
- **九一八 autumn 贴图门坐标全错**：`_doorSpecs` 只登记非 autumn 名字，`_autumn` 房屋 `DoorX` 全 fallback 到 0.18，门画错且沙包避让算错门口；已补齐三个 autumn 变体。
- **大地图静态标注漏门控**：`Tag("嫩江 · 江桥 1931.11")` 是 `Label` 节点，动态路线拆段后它仍提前显示；改为 `Refresh()` 按 `N918Done` 控 `Visible`，江桥图钉同步门控，并补上通关后首次进图的 `MapArt.Progress = 1`（否则第一段路线凭空少一截）。
- **室内截图异步竞态**：`CaptureRoom.SaveShot()` 是 `async void`，调用后立即切房间会拍到下一间；改为 `SaveShot(name, onSaved)` 在保存完成回调里才 `BuildRoom()`。
- **CanvasLayer 拍不到**：`HouseInteriorUi : CanvasLayer` 在 `SubViewport` 里读不到；新增 `scenes/CaptureRoom.tscn` 直接渲染普通 `Control` 的 `RoomBg` 预览做画风验收。

#### 验证

`dotnet build witness.csproj` → **Build succeeded / 0 Error**（3 个既有 warning）；四个实机截图场景 `CaptureRoom` / `CaptureMap` / `CaptureN918` / `Capture` 全部出图并目视复核：第一章地图无江桥标注、通关后第二段路线与圈注出现、两关房屋门口均无沙包、地面读成连续野地、室内四间房对应正确。详见 `docs/V364_CHANGES.md`。

#### 如实标注的差距（未达标项，不吹）

- 室内是**程序化**钢笔淡彩，笔触丰富度仍不及 `assets/art` 里 AI 生成的水彩贴图；**交互纸签仍偏白、设备轮廓仍偏硬边矩形**，视觉上还没完全摆脱「矩形 + 标签」观感。
- 草地虽然连成片，但草丛密度与真实草原仍有距离——纯线条绘制的天花板就在这里。

### 九一八事变初秋化支线（2026-11 并入 nakamura85）

> 九一八事变（1931.9.18 沈阳柳条湖）原本只是进江桥前的一次性档案弹窗（v3.1）。本支线把它做成一个**可进入、可搜索的初秋叙事场景**，与江桥试玩关并列，走 `Main.StartN918() → N918Level`。`feat/n918-level` 分支与 `nakamura85` 无共同祖先、无法直接 merge，故以**文件级移植**并入：33 个九一八专属新文件整取，共享文件只并入九一八专属 hunk（设计/复用/美术规格见 `docs/N918_DESIGN.md` / `N918_REUSE_MAP.md` / `N918_ART_SPEC.md`）。

- **初秋化美术（暖色调非雪原）**：沈阳柳条湖场景改为初秋夜——枯黄草坡、暖橙远山、榆树残叶、惨白月亮，与江桥的严冬雪原区分开；新增 `assets/art/backdrop/*_autumn.png`（mountains/village/tree_elm）与 `assets/art/props/*_autumn.png`（bridge / 近景民居 intact·ruined·skeleton·posts·burned）。
- **破损白边透明根修**：近景破损/焚毁民居贴图原本残留一圈白底白边（开口、窗户、破洞处），被玩家截图指出。用像素级「封闭近白区域清除」（flood-fill 围死的白底口袋 + alpha 外扩吃抗锯齿边）把白边整圈抠成透明——实测残留浅灰从数万 px 降到 1985–3722 px（仅建筑本体），开口/窗户不再有白底。
- **radio_station 浮空/棋盘格修净**：电台小屋贴图（`assets/art/props/radio_station.png`）原本底部留白约 251px 导致贴地悬浮、天线帆布为透明露出棋盘格。已裁掉底部留白（落地）、把帆布/旗布填成不透明实色（消除棋盘格），并把位置由 x4620 移到 **x4000**，落于江桥桥台之前的地面、不再压桥面 / 铁轨结构（玩家诉求：房子必须在地面、不在铁轨/桥上）。随后补：把 `radio_station` 登记进 `HouseEaveRow`（eave=770，1024×1285 实测），纠正此前走 `return 400f` 兜底的偏宽比例；并在烟雾开关里让通信据点 `return`（不再从建筑正中冒民用炊烟）。
- **室内三种固定常识格局（住家 / 通信据点机房 / 半塌农舍）**：进屋后看到墙面/家具/光影构成的真实空间，按房屋类型画**三种固定布局**——**住家**（炕 / 灶台 / 桌子 / 柜子，两间民居左右变体）、**通信据点机房**（发电机 / 电闸 / 发信机 / 地图桌）、**半塌焚毁农舍**（残货架 / 木箱 / 灰烬堆），搜索物件按常识摆到对应家具上（信压灶台、灰烬在柜子、发信机在角落）。房子内的布局是固定的、符合常识的，不再是千篇一律的通用图。点击即搜刮并落 `WitnessState.N918Loot`；落款按支线参数化（江桥=「江桥抗战官兵家书意象改写」、九一八=「东北军官兵家书意象改写」），虚构人物伦理提示不变。
- **初秋地表生动化（枯草丛 / 小石块 / 泥土斑 / 野草）**：九一八地面原先是一整片纯色土黄、毫无生机（玩家诉求「草地很枯燥没有任何生动」）。在 `GroundArt.DrawGroundDetailing()` 用固定随机种子沿地表正弦曲线程序化撒入枯草丛、扁石、贴地土斑与带穗野草，避开房屋脚、不画到桥前江面；每帧重画结果一致不会抖。地面从「一片死色」变成有层次、有细节的野地。
- **两关远景布局差异化（不再每关一模一样）**：九一八与江桥的 `VillageHouses` 远景村落原先除了贴图后缀完全一致（同 X / 同高低 / 同烟种），所以「全部关卡的布局一模一样、很单调」。现已为两关各写**独立排布**——九一八 = 沈阳北大营驻军营盘（密集营房 + 多黑烟 + 一座木瞭望塔地标），江桥 = 江畔守军村落（稀疏、以 intact 为主 + 一两处被掀 + 一座土垒旗杆地标）；另各加一盏 `DrawMidLandmark()` 程序化地标，两关天际线一眼可辨。
- **东亚大地图按时间线推进（九一八在先、江桥在后）**：进入按钮改为 `EnterCurrent()`——`N918Done` 前先打九一八（沈阳），通关后地图自动把红图钉 / 圈注 / 章节列表高亮推进到嫩江江桥；入口文案与左下提示随当前章节变化（「进入关卡 · 九一八事变 1931.9.18」→「进入关卡 · 嫩江江桥 1931.11.4」）。九一八真正通关后标记 `MapNote918`，进入江桥前不再重复弹九一八档案。
- **状态机并入 WitnessState**：新增 9 个九一八字段（`N918Done / N918Testimony / N918Loot / N918EnvelopeCount / N918RadioSent / N918Resist / N918Visited / N918Powered / N918Refugees`），跨场持久化搜刮/证言/电台状态。`dotnet build` 在 nakamura85 代码下 **0 error** 通过验证。

## 关卡玩法

### 嫩江江桥 1931.11.4

- **移动**：A/D 或 ←/→ 左右推进；**空格**跳跃；**S / ↓** 蹲下
- **射击**：鼠标左键（朝鼠标指向开火；立姿据枪 / 跪蹲 / 低姿匍匐按军人条令出专姿立绘）
- **记录**：靠近发光的证词点，**按住 E 约 1.2 秒**（进度环）—— 被敌兵看见时会被打断
- **解谜设计**：证言必须完整记录三份（机枪手赵永生、卫生员李桂兰、铁路工人孙德山），缺一不可通关。现场散落的物证碎片（歪把子零件、绷带卷、铁轨碎段）是完整还原证词的关键。

### 交互机制（嫩江江桥 / 九一八支线通用）

- **进入房屋 / 搜刮**：走到近景民居（残破 / 焚毁）前按 **E** 进入屋内，点击搜刮点（子弹 / 手榴弹 / 遗言字条 / 线索字条 / 灰烬），长按撬开**宝箱**（约 1.4 秒，60% 开出弹药+手榴弹，40% 冻锁失败）。搜索进度自动保存。
- **拾取掉枪**：日军阵亡后尸体旁会掉落步枪，靠近按 **E** 拾取——可能枪栓冻死开不了（0 弹），也可能带 2~8 发可用子弹，自动补进弹仓。
- **手榴弹**：按 **G** 投掷木柄手榴弹（抛物线 + 落地反弹 + 2.2 秒引信），范围杀伤靠近的日军；弹仓打空时优先去捡枪或进屋搜弹。
- **沙包掩体**：蹲（S / ↓）或匍匐（Ctrl / C）贴住沙墙即进入「掩体」状态，日军命中率骤降；敌兵会前压逼近。**v3.64 起沙堆落位避开所有房屋门口与占地**，不再挡住进屋动线。
- **手榴弹与爆炸（v3.59–v3.61）**：按 **G** 投掷 M24 木柄手榴弹（抛物线 + 落地横躺 + 2.2 秒引信，方向跟鼠标）；敌兵投九一式手榴弹。爆炸按现实装药建模（65g TNT、重创带 5m≈337px、破片带 8m≈539px，1px≈1.484cm），分四层火光烟尘并让沙包物理飞散；**沙包后仍会受伤扣血**（有掩体 2 心 / 无掩体 3 心），雪地留焦痕。
- **角色状态（v3.61–v3.62）**：玩家残血时移速 ×0.78 并流血；敌兵负伤后 55% 撤退 / 45% 卧倒，不再呆冲；启停加减速平滑，枪口俯仰跟随鼠标高度。
- **野外植被（v3.64）**：草地 / 野地按斑块连续生成，成片草色带 + 密集草丛，不再是「一颗两颗草」。

## 如何运行（小白版，3 步）

1. **装 .NET 8 SDK**（编译 C# 必需）
   到 https://dotnet.microsoft.com/download/dotnet/8.0 下载并安装 .NET 8.0 SDK。

2. **装「.NET 版」Godot 4.7**（注意：不是普通版！）
   到 https://github.com/godotengine/godot-builds/releases 下载 **Godot_v4.7-stable_mono_win64.exe**（文件名带 `mono` 才是 .NET 版）。

3. **打开游戏**
   双击 Godot exe → 点「导入」→ 选择本项目的 `project.godot` → 打开 → 按 **F5** 运行。

> 也可以先在命令行运行 `dotnet build witness.sln` 确认编译通过（0 错误）再进 Godot。

## 给开发者的提示

- **C# 脚本文件名必须与类名大小写完全一致**，否则 Godot 会静默跳过注册
- `project.godot` 必须显式写 `[dotnet] project/assembly_name="witness"`，否则报「DLL 找不到」
- 自动截图巡游：开发时把 `scripts/Capture.cs`（或旧 `scripts/VerifyTour.cs`）临时挂到 `[autoload]` 再正常运行游戏，跑完自动退出并输出到 `docs/screenshots/`；**push 前必须移除**
- headless 测试：`Godot_v4.7-stable_mono_win64.exe --headless --path . --script res://tests/SmokeTest.cs`
- 背景贴图管线：AI 图生图生成 → `_gen/backdrop/process.py` 去白底抠图 + 紧裁 + 水印条 → 落 `assets/art/backdrop/` 并让 Godot 生成 `.import`
- **刷新 README 画廊的标准流程（v3.64 起）**：改过贴图先 `--headless --import --path .` 重新导入；再跑 `Godot_v4.7.2-stable_mono_win64_console.exe --path . --rendering-driver opengl3 --resolution 1280x720 scenes/Capture.tscn`（另有 `CaptureN918` / `CaptureMap` / `CaptureRoom`），真帧落在项目根 `_shots/`（已 gitignore）→ 映射进 `docs/screenshots/` → **bump README `?v=` 版本号 +1** → 提交并推送 `nakamura85`。headless 主视口 dummy 渲染器读不到纹理，必须靠 `SubViewport` + `opengl3` 才能出真图；`triangulation failed` 是前景雪檐的历史无害警告。
