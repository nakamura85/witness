# 见证者（Witness）· v2.0 手绘漫画风二战亚洲战场叙事游戏

> 二战的历史不是从 1937 年才开始的。要还原事实，就得从源头讲起——1895 年的马关条约、1910 年的日韩合并条约，殖民如何一步步吞下朝鲜半岛与台湾地区，直到 1931 年九一八、1937 年的南京。

一款 **2D 叙事严肃游戏**（Godot 4.7.2 .NET / C#）。

## 美术风格

**手绘上色漫画风（Hand-drawn cel-shading manga）** —— 粗墨描边、平涂色块、卡通高光，参考《勇敢的心：世界大战》的手绘质感。游戏采用**混合美术管线**，贴图层与程序化绘制共用同一坐标系，保证整画风格统一：

- **程序化手绘层（纯 `Node2D._Draw()`）**：UI / 菜单 / 暴风雪·飘雪·灯笼光晕·暗角等特效、尸体与血迹、地形细节（沙袋、桥墩、桁架、弹坑、铁轨、碉堡），风格统一入口为 `scripts/InkStyle.cs`（墨色描边 `InkColor` + 平涂色板 + `PenStroke` 工具方法）。
- **AI 生成贴图层（图生图，保持同款水彩漫画画风）**：
  - **史实军服角色立绘**（`assets/art/sprites/`）：东北军 1931 灰蓝棉服护耳棉帽青天白日帽徽、日军昭五式大檐帽黄星三八式步枪；含立姿 / 据枪 / 蹲 / 匍匐专姿（`soldier_na_aim` / `_crouch` / `_prone`）、尸体（`*_corpse`）、NPC / 难民 / 建筑 / 道具。
  - **视差背景贴图**（`assets/art/backdrop/`，layer by layer 厚度 / 纵深感）：雪山 `mountains`、东北民居村落 `village`、榆树 `tree_elm`、白桦 `tree_birch`、柳丛 `willow`、雪地枯草 `grass`，以 `DrawTextureRect` + `DrawSetTransform` 合成进 Far / Mid / Near / Fore 四层视差。
- **图层**：4 层视差（Far 0.06 / Mid 0.24 / Near 0.55 / Fore 1.32；ZIndex Far -40 / Mid -30 / Near -20 / Player 0 / Enemy 2 / Fore 5）。贴图层与程序化层叠加产生厚度与纵深。

## 游戏流程

1. **内容警告** → **标题画面**（`assets/art/title.jpg` 古城墙雪景照片全屏铺底 + 程序化叠层：飘雪粒子 + 灯笼暖光晕 + 暗角 vignette，手绘漫画风菜单）
2. **东亚大地图**（手绘漫画风时间线 Hub：朝鲜半岛 & 台湾地区的殖民标记、1895–1945 日军进军路线、档案纸条）
3. **纸条档案**（《马关条约》《日韩合并条约》原文、殖民动机、历史代价）
4. **嫩江江桥 1931.11.4 关卡**（手绘漫画风横版 2D 关卡，4 层视差雪原战场）
5. **记录证言**：东北军幸存者口述史料，走到位置按住 E 约 1.2 秒记录
6. **通关档案** → 史料馆

## 近期更新要点（v2.0）

> 以下修复全部**本机 Godot 4.7.2 mono 实机运行验证**（自动化截图脚本 `scripts/Capture.cs` 巡游 5 阶段截图，整轮 0 报错、0 三角化失败）。立绘与背景贴图由 ImageGen 以旧图为底图**图生图重绘**，画风一致。

- **背景鬼畜 + 白线闪烁根除**：背景三绘制函数里的 `Randomize()` 改为固定种子（19311104/19311105/19311106），删时间风摆，静止时不重绘——玩家不动画面一像素不变，白线闪烁随背景静止根除。
- **史实军服重绘**（图生图）：东北军灰蓝棉服护耳棉帽帽徽、日军昭五式大檐帽黄星三八式步枪；后续章节军服规范（国军中央军 / 八路军）沿用同一管线。
- **军事标准专姿立绘**：立姿据枪 / 跪蹲持枪 / 低姿匍匐整张专项姿势立绘切换；枪口锚点按立绘实测（PIL 逐像素测枪管高度比例），子弹起点直接取立绘枪口锚点，火光 / 弹道与枪管尖完全对齐。
- **据枪 / 蹲 / 匍匐人物比例修正**：旧实现把蹲、匍匐整张立绘整体 Y 轴压扁到 62% / 30%，导致"人物缩小很多"的错觉；改为按真实人体比例（蹲姿 ≈ 身高 74%、匍匐按躯干长度 = 站立身高）渲染，并重新对齐匍匐影子。
- **视差背景贴图重制**（layer by layer 厚度感）：雪山、东北民居村落、榆树 / 白桦 / 柳丛、雪地枯草，全部按史实军服立绘同款水彩漫画画风图生图生成，合成进 Far / Mid / Near / Fore 四层视差，保留程序化桥 / 沙袋 / 弹坑 / 铁轨 / 碉堡 / 电报杆 / 弃车与雪山程序化兜底。

## 关卡玩法

### 嫩江江桥 1931.11.4

- **移动**：A/D 或 ←/→ 左右推进；**空格**跳跃；**S / ↓** 蹲下
- **射击**：鼠标左键（朝鼠标指向开火；立姿据枪 / 跪蹲 / 低姿匍匐按军人条令出专姿立绘）
- **记录**：靠近发光的证词点，**按住 E 约 1.2 秒**（进度环）—— 被敌兵看见时会被打断
- **解谜设计**：证言必须完整记录三份（机枪手赵永生、卫生员李桂兰、铁路工人孙德山），缺一不可通关。现场散落的物证碎片（歪把子零件、绷带卷、铁轨碎段）是完整还原证词的关键。

## 如何运行（小白版，3 步）

1. **装 .NET 8 SDK**（编译 C# 必需）
   到 https://dotnet.microsoft.com/download/dotnet/8.0 下载并安装 .NET 8.0 SDK。

2. **装「.NET 版」Godot 4.7**（注意：不是普通版！）
   到 https://github.com/godotengine/godot-builds/releases 下载 **Godot_v4.7-stable_mono_win64.exe**（文件名带 `mono` 才是 .NET 版）。

3. **打开游戏**
   双击 Godot exe → 点「导入」→ 选择本项目的 `project.godot` → 打开 → 按 **F5** 运行。

> 也可以先在命令行运行 `dotnet build witness.sln` 确认编译通过（0 错误）再进 Godot。

## 内容警告

本游戏取材于二战亚洲战场的真实历史，包含战争、屠杀与性暴力的**记述与暗示**（均来自公开史料，不含血腥画面）。若你正处于创伤恢复期，请谨慎游玩。

## 史料出处（游戏内容的边界）

所有事件、数字、人物均来自公开史料：

- 《马关条约》（1895）与《日韩合并条约》（1910）条约文本
- 《黑龙江省志·铁路志》与江桥抗战口述史料
- 《拉贝日记》（1997 年出版）
- 《魏特琳日记》（2000 年出版）
- 约翰·马吉牧师 16mm 实拍影像（后成为东京审判证据）
- 远东国际军事法庭（IMTFE）判决书（1948）
- 南京审判战犯军事法庭判决（1946–1947）

**具名真实人物首次出场时**，屏幕下方会标注「真实历史人物 · 详见史料卡 X」。在世受害者一律不使用真名。

## 给开发者的提示

- **C# 脚本文件名必须与类名大小写完全一致**，否则 Godot 会静默跳过注册
- `project.godot` 必须显式写 `[dotnet] project/assembly_name="witness"`，否则报「DLL 找不到」
- 自动截图巡游：开发时把 `scripts/Capture.cs`（或旧 `scripts/VerifyTour.cs`）临时挂到 `[autoload]` 再正常运行游戏，跑完自动退出并输出到 `docs/screenshots/`；**push 前必须移除**
- headless 测试：`Godot_v4.7-stable_mono_win64.exe --headless --path . --script res://tests/SmokeTest.cs`
