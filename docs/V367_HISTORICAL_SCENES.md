## 依据等级

| 等级 | 含义 | 处理 |
|---|---|---|
| A · 史料明确 | S1/S2/S3 直接写明的场景级事实 | 必须呈现，且**不得**被另一关复制 |
| B · 合理复原 | 由 A 推出的环境（季节、植被、土路、营房形制） | 可呈现，注明是复原 |
| C · 游戏化 / 虚构 | 玩法装置、人物、道具、对白 | 允许存在，但不得写成史实 |
| ✗ · 明确排除 | 史实上此地不存在，误从别关搬来 | **删除**，见下方「复制残留清理」 |

## 复制残留清理清单（v3.67）

`N918Level.cs` 早期是 `JiangqiaoLevel.cs` 的整份移植，v3.66 只删了桥和冰江，
骨架仍同构。本轮按上表逐项清理：

| # | 残留 | 处理 | 依据 |
|---|---|---|---|
| R1 | `GroundArt._Draw()` 里 26 条「冰面裂缝与车辙」 | 删除，换成说明注释 | ✗ 初秋柳条湖无冰封江面 |
| R2 | `DrawTrenchLines()` 调用（雪原战壕 + 翻雪弹药箱） | 改调 `DrawRailEmbankment()` | ✗ 江桥阵地不搬到柳条湖 |
| R3 | `DrawMidLandmark()` 的木瞭望塔 | 重画为北大营营盘（营房 / 营门 / 旗杆） | A/B · S2 |
| R4 | `BuildHouses()` 沿用江桥坐标与「压在桥面 4457-4902」注释 | 按九一动线重排坐标、改写注释；ID 保留以保流程 | B · 场景动线区分 |
| R5 | 两关 `BuildHouses` / `DrawFar/Mid/Near/GroundBand/Fore` 逐行同构 | 保留各自独有的地标、地面与房屋分布；江桥侧不动 | 本表「两关对照」 |

> 诚实说明：**代码层仍是两个同构的 `*.cs` 文件**（同一套渲染管线、同类内部结构），
> 本轮做到的是「场景元素、地标、地形、房屋动线按史实分开」，
> 不是把两个关卡重构成两套独立引擎。要彻底拆成共享基类 + 关卡数据，属于后续架构工作。

## 室内格局（本轮另一半改动）

| # | 旧（v3.64–v3.66） | 新（v3.67） |
|---|---|---|
| I1 | `HouseInteriorUi : CanvasLayer` 全屏面板 + 一排 `Spot : Button` 文字标签 | `InteriorRoom`：漫画风房间 + 门 + **实体物件** + **能走动的玩家小人** |
| I2 | 提示「点一下就能查看」 | `A/D` 或 `←/→` 走动，靠近物件按 `E` 查看，走到左侧门口按 `E` 离开 |
| I3 | 物件是文字按钮，位置只是标签坐标 | 物件按 `RoomType` 落到家具锚点上（住家 / 通信据点 / 焚毁仓库三种格局），住家 variant 左右镜像 |
| I4 | 每张屋子看起来一样 | 按房间类型与 `houseId` 播种布局，不同屋不完全一样 |
| I5 | 搜刮 / 撬箱 / 合闸 / 发报逻辑 | **完全复用**（`OnSpot` / `MarkDone` / 长按进度），只换呈现层 |

卡通高光小圆点 / 短直线、硬边压扁椭圆接触阴影；无渐变、无羽化、无纸纹水痕。
新增统一入口 `scripts/InteriorExplore.cs`，两关室内共用。
