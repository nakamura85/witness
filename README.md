# 见证者（Witness）· v2.9 手绘漫画风二战亚洲战场叙事游戏

> 二战的历史不是从 1937 年才开始的。要还原事实，就得从源头讲起——1895 年的马关条约、1910 年的日韩合并条约，殖民如何一步步吞下朝鲜半岛与台湾地区，直到 1931 年九一八、1937 年的南京。

一款 **2D 叙事严肃游戏**（Godot 4.7.2 .NET / C#）。

## 美术风格

**手绘上色漫画风（Hand-drawn cel-shading manga）** —— 粗墨描边、平涂色块、卡通高光，参考《勇敢的心：世界大战》的手绘质感。游戏采用**混合美术管线**，贴图层与程序化绘制共用同一坐标系，保证整画风格统一：

- **程序化手绘层（纯 `Node2D._Draw()`）**：UI / 菜单 / 暴风雪·飘雪·灯笼光晕·暗角等特效、尸体与血迹、地形细节（沙袋、桥墩、桁架、弹坑、铁轨、碉堡），风格统一入口为 `scripts/InkStyle.cs`（墨色描边 `InkColor` + 平涂色板 + `PenStroke` 工具方法）。
- **AI 生成贴图层（图生图，保持同款水彩漫画画风）**：
  - **史实军服角色立绘**（`assets/art/sprites/`）：东北军 1931 灰蓝棉服护耳棉帽青天白日帽徽、日军昭五式大檐帽黄星三八式步枪；含立姿 / 据枪 / 蹲 / 匍匐专姿（`soldier_na_aim` / `_crouch` / `_prone`）、**阵亡尸体**（`corpse_na/ija_prone/supine` 俯卧 / 仰卧）、NPC / 难民 / 建筑 / 道具。
  - **视差背景贴图**（`assets/art/backdrop/`，layer by layer 厚度 / 纵深感）：雪山 `mountains`、东北民居村落（战后残破）`village_ruined`、榆树 `tree_elm`、白桦 `tree_birch`、柳丛 `willow`、雪地枯草 `grass`，以 `DrawTextureRect` + `DrawSetTransform` 合成进 Far / Mid / Near / Fore 四层视差。
  - **战场物件贴图**（`assets/art/props/`）：沙袋掩体堆 `sandbags`、弹药木箱 `crate`、可进入的残破 / 焚毁近景民居 `house_ruined_near` / `house_burned_near`、含桥墩桁架的江桥 `bridge`，与角色 / 背景同一管线出图。
- **图层**：4 层视差（Far 0.06 / Mid 0.24 / Near 0.55 / Fore 1.32；ZIndex Far -40 / Mid -30 / Near -20 / Player 0 / Enemy 2 / Fore 5）。贴图层与程序化层叠加产生厚度与纵深。

## 游戏流程

1. **内容警告** → **标题画面**（`assets/art/title.jpg` 古城墙雪景照片全屏铺底 + 程序化叠层：飘雪粒子 + 灯笼暖光晕 + 暗角 vignette，手绘漫画风菜单）
2. **东亚大地图**（手绘漫画风时间线 Hub：朝鲜半岛 & 台湾地区的殖民标记、1895–1945 日军进军路线、档案纸条）
3. **纸条档案**（《马关条约》《日韩合并条约》原文、殖民动机、历史代价）

5. **记录证言**：东北军幸存者口述史料，走到位置按住 E 约 1.2 秒记录
6. **通关档案** → 史料馆

### v2.6 枪边残影根修 + 动态烟与火

- **日军手上 / 枪边残影根修**（v2.6）：纸娃娃的下半身原本是**沿贴图中线竖着切两半**——前腿大腿横跨中线被切成两半（走起来就是"大腿跟小腿分离"），斜挎在手上的三八式步枪正好插进腿部区域被**复制进两条腿片**，腿一摆动，枪的复制件就从手里飞出去（就是玩家看到的"日本兵的手和枪那边有残影"）。

### v2.9 贴图缓存串色根修 + 埋雪重做 + 验收图不再污染正式图库

- **`SoftSnow` 缓存 key 串色根修（本轮最硬的一个 bug）**（v2.9）：软衰减贴图按「颜色 + alpha」缓存，但 key 写的是 `tint.GetHashCode() ^ (int)(alpha*1000)`。Godot 的 C# `Color.GetHashCode()` 把 R/G/B 从 float **直接截断成 uint**（`0.90f` 和 `0.55f` 都变成 `0`），而且**不算 alpha**——于是所有颜色哈希到同一个数，key 里只剩 alpha 一个变量。结果是：**任何两个用了相同 alpha 的调用方共用同一张贴图**，颜色完全被忽略。
  - 现场表现：尸体旁边本该是浅色雪堆的地方，拿到的是 `EnterableHouse` 缓存的**近黑屋影**贴图，雪面上凭空多出一块硬边深灰多边形；反过来，深色阴影又会拿到浅色贴图而消失。
  - 修法：key 改为按 `R/G/B/A` 的确切字节拼装（`((int)(tint.R*255)<<24) ^ … ^ (int)(alpha*1000)*7919`），保证任何两次请求都不会撞桶。
- **埋雪三档重做（视觉上原本毫无区别）**（v2.9）：旧埋深只有 5px，而整支枪才 10px 高，三档（平躺 / 半埋 / 只露枪管）画出来**几乎一模一样**。现在雪堆锚定在**雪面**（不再跟着枪一起下沉），堆体由多层软衰减团叠出真实高度与圆顶，枪身随埋深整体下沉；同时把雪堆色调校到与实测雪面（白天约 `0.74`）一致，雪堆是「融进地面」而不是「浮在地面的一块白斑」。`WeaponPickup` 与 `CorpseActor` 两处掉枪统一走这套逻辑。
- **尸体掉枪「白纸片」根修**（v2.9）：`CorpseActor` 里的掉枪还留着 v2.8 已在 `WeaponPickup` 修掉的硬边白色长条（`DrawRect` 68×3），同一处 bug 漏改了一个文件。现已一并改成软衰减带 + 分档埋雪。

## 关卡玩法

### 嫩江江桥 1931.11.4

- **移动**：A/D 或 ←/→ 左右推进；**空格**跳跃；**S / ↓** 蹲下
- **射击**：鼠标左键（朝鼠标指向开火；立姿据枪 / 跪蹲 / 低姿匍匐按军人条令出专姿立绘）
- **记录**：靠近发光的证词点，**按住 E 约 1.2 秒**（进度环）—— 被敌兵看见时会被打断
- **解谜设计**：证言必须完整记录三份（机枪手赵永生、卫生员李桂兰、铁路工人孙德山），缺一不可通关。现场散落的物证碎片（歪把子零件、绷带卷、铁轨碎段）是完整还原证词的关键。

### v2.2 新增交互（嫩江江桥）

- **进入房屋 / 搜刮**：走到近景民居（残破 / 焚毁）前按 **E** 进入屋内，点击搜刮点（子弹 / 手榴弹 / 遗言字条 / 线索字条 / 灰烬），长按撬开**宝箱**（约 1.4 秒，60% 开出弹药+手榴弹，40% 冻锁失败）。搜索进度自动保存。
- **拾取掉枪**：日军阵亡后尸体旁会掉落步枪，靠近按 **E** 拾取——可能枪栓冻死开不了（0 弹），也可能带 2~8 发可用子弹，自动补进弹仓。
- **手榴弹**：按 **G** 投掷木柄手榴弹（抛物线 + 落地反弹 + 2.2 秒引信），范围杀伤靠近的日军；弹仓打空时优先去捡枪或进屋搜弹。
- **沙包掩体**：蹲（S / ↓）或匍匐（Ctrl / C）贴住沙墙即进入「掩体」状态，日军命中率骤降；敌兵会前压逼近。

## 如何运行（小白版，3 步）

1. **装 .NET 8 SDK**（编译 C# 必需）
   到 https://dotnet.microsoft.com/download/dotnet/8.0 下载并安装 .NET 8.0 SDK。

2. **装「.NET 版」Godot 4.7**（注意：不是普通版！）
   到 https://github.com/godotengine/godot-builds/releases 下载 **Godot_v4.7-stable_mono_win64.exe**（文件名带 `mono` 才是 .NET 版）。

3. **打开游戏**
   双击 Godot exe → 点「导入」→ 选择本项目的 `project.godot` → 打开 → 按 **F5** 运行。

> 也可以先在命令行运行 `dotnet build witness.sln` 确认编译通过（0 错误）再进 Godot。

## 给开发者的提示

- **C# 脚本文件名必须与类名大小写完全一致**，否则 Godot 会静默跳过注册
- `project.godot` 必须显式写 `[dotnet] project/assembly_name="witness"`，否则报「DLL 找不到」
- 自动截图巡游：开发时把 `scripts/Capture.cs`（或旧 `scripts/VerifyTour.cs`）临时挂到 `[autoload]` 再正常运行游戏，跑完自动退出并输出到 `docs/screenshots/`；**push 前必须移除**
- headless 测试：`Godot_v4.7-stable_mono_win64.exe --headless --path . --script res://tests/SmokeTest.cs`
- 背景贴图管线：AI 图生图生成 → `_gen/backdrop/process.py` 去白底抠图 + 紧裁 + 水印条 → 落 `assets/art/backdrop/` 并让 Godot 生成 `.import`
