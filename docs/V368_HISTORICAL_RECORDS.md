# v3.68 真实烈士与史料档案对照表

> 用户 2026-11-12 要求：「这些记录不要以对话格子的方式呈现，而是以真实纸张的方式呈现……
> 纸张不要全部都一样，也是对真实的真相来还原。还有那些名字要用真实的烈士人名来呈现，
> 尤其是在对应的战役牺牲的烈士人名。」
>
> 本表是**唯一对照表**：游戏里出现的每一个真实姓名，都要能在这里查到出处与归属战役。
> 新增档案前先查本表，不得拿化名顶替、不得跨战役挪用。

---

## 一、红线（不可突破）

| # | 规则 |
|---|---|
| R1 | **绝不给真实烈士编造家书、遗言、第一人称口述**。所有文本改为第三人称的「档案 / 阵亡通报 / 通电摘录 / 战地记录」体裁，并在末尾注明「本文为据公开史料整理的档案摘录，非烈士本人遗书或原话」。 |
| R2 | 只用可考的姓名、职务、部队、时间、地点；查不到姓名的地方如实写「姓名未详 / 名录散佚」，**不拿化名填充**。无名本身也是史实的一部分。 |
| R3 | 每位烈士只出现在**其实际牺牲的战役**对应关卡。跨战役人物必须写明真实殉国时间与地点，不能并入本役阵亡名录。 |
| R4 | 游戏化内容（烧毁纸页、通信据点发报、可探索房间）在文本里明确标注为游戏化呈现，不与史实事件混写。 |
| R5 | AI 生成的美术资源需人工精修与合规确认（见文末「待精修」）。 |

v3.67 及以前的做法是「化名 + 第一人称文学独白 + 末尾一句『人物为复合虚构』」。v3.68 已全部移除：
`王福顺`、`李大山`、`张王氏`、`秀兰`、`小赵`、`赵永生`、`李桂兰`、`孙德山`、
`永胜`、`熙`（虚构落款）等一律不再出现。

## 四、呈现方式（v3.68）

| 位置 | 旧（v3.67 及以前） | 新（v3.68） |
|---|---|---|
| 8 处 `FieldNoteUi`（地图纸条、屋内信件/遗书/文件、两关证言、档案） | `PanelContainer + StyleBoxFlat` 米黄矩形卡片 = 对话格子 | `BurntPaperPanel`：手绘上色漫画风的真实纸张，撕边锯齿、局部焦褐带、少许烧穿孔、翻卷角、折痕、灰烬点、硬边投影 |
| 底部剧情对白 `DialogueUi` | 纸色矩形 + 系统按钮 | 同上；每段对白按文本哈希换 seed，纸张不同 |
| 两关结算面板 `LevelEndUi` / `N918LevelEndUi` | 米黄矩形卡片 | 同上 |
| 史料卡 `CardOverlayUi` | 米黄矩形卡片 | 同上，seed 随卡号变化 |
| 屋内提示牌 / 结果条 | 米黄矩形 UI 标签 | `PaperSlip` 撕边小纸条 |
| 按钮 | 系统默认灰按钮 | `PaperButtonStyle`：米黄土实色 + 3px 深墨棕粗框 + 硬投影 |

**「纸张不要全部都一样」怎么实现**：`BurntPaperArt.StableHash(date + "|" + title)` 生成 seed，
控制焦边落在哪条边、缺口深度、烧洞数量与位置、卷角方向、折痕位置、纸色冷暖微差、
摆放角度（±0.3°）。同一份记录每次打开一致（稳定哈希，不用 `string.GetHashCode`，
后者 .NET 每次进程会随机化）；不同记录必然不同。所有绘制走 `InkStyle.cs` 的
3px 深墨棕粗描边 + 三档平涂 + 卡通高光短线，无渐变、无羽化、无纸纹水痕。

**收尾自查修正（正文可读性）**：首轮实机帧里出现烧穿孔 / 折痕正好压住正文与阵亡数字
（第 1、2 张纸最明显）。纸上写的是真实烈士档案，焦痕不能把姓名与数字啃掉，故收窄
`BurntPaperArt.DrawSheet`：烧穿孔一律落在上下 12–28px 留白带，折痕落在 8%–13% /
88%–93% 高度带且透明度降到 0.30，`BurntPaperPanel` 的 48/42/46px 内边距继续给焦边留安全区。
重新编译并全量重跑五个截图场景后逐张复核，正文零遮挡。
