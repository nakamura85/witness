# 见证者（Witness）· 二战亚洲战场手绘漫画风叙事游戏

> 二战的历史不是从 1937 年才开始的。要还原事实，就得从源头讲起——1895 年的马关条约、1910 年的日韩合并条约，殖民如何一步步吞下朝鲜半岛与台湾地区，直到 1931 年九一八、1937 年的南京。

一款 **2D 叙事严肃游戏**（Godot 4.7.2 .NET / C#）。

## 美术风格

**手绘上色漫画风（Hand-drawn cel-shading manga）** —— 粗墨描边、平涂色块、卡通高光，参考《勇敢的心：世界大战》的手绘质感。游戏采用**混合美术管线**，贴图层与程序化绘制共用同一坐标系，保证整画风格统一：

- **程序化手绘层（纯 `Node2D._Draw()`）**：UI / 菜单 / 暴风雪·飘雪·灯笼光晕·暗角等特效、尸体与血迹、地形细节（沙袋、弹坑、铁轨、碉堡；桥墩 / 桁架仅江桥关卡），风格统一入口为 `scripts/InkStyle.cs`（墨色描边 `InkColor` + 平涂色板 + `PenStroke` 工具方法）。
- **AI 生成贴图层（图生图，统一手绘上色漫画风；早期个别贴图仍待重做，见 v3.66 差距）**：
  - **史实军服角色立绘**（`assets/art/sprites/`）：东北军 1931 灰蓝棉服护耳棉帽青天白日帽徽、日军昭五式大檐帽黄星三八式步枪；含立姿 / 据枪 / 蹲 / 匍匐专姿（`soldier_na_aim` / `_crouch` / `_prone`）、**阵亡尸体**（`corpse_na/ija_prone/supine` 俯卧 / 仰卧）、NPC / 难民 / 建筑 / 道具。
  - **视差背景贴图**（`assets/art/backdrop/`，layer by layer 厚度 / 纵深感）：雪山 `mountains`、东北民居村落（战后残破）`village_ruined`、榆树 `tree_elm`、白桦 `tree_birch`、柳丛 `willow`、雪地枯草 `grass`，以 `DrawTextureRect` + `DrawSetTransform` 合成进 Far / Mid / Near / Fore 四层视差。初秋支线另含 `*_autumn` 系列（枯黄草坡 / 暖橙远山 / 残叶榆树 / 惨白月亮）。
  - **战场物件贴图**（`assets/art/props/`）：沙袋掩体堆 `sandbags`、弹药木箱 `crate`、可进入的残破 / 焚毁近景民居 `house_ruined_near` / `house_burned_near`、含桥墩桁架的江桥 `bridge`（**仅江桥关卡使用**）、电台小屋 `radio_station`，与角色 / 背景同一管线出图；`bridge_autumn.png`（九一八关卡的旧桥贴图）v3.66 起已停用。
- **图层**：4 层视差（Far 0.06 / Mid 0.24 / Near 0.55 / Fore 1.32；ZIndex Far -40 / Mid -30 / Near -20 / Player 0 / Enemy 2 / Fore 5）。贴图层与程序化层叠加产生厚度与纵深。
- **铁轨 / 手榴弹漫画风唯一入口（v3.66 新增）**：`scripts/MangaPropArt.cs` 统一提供道砟 / 枕木 / 钢轨 / 桥面钢板 / 断轨口与 M24 木柄弹 / 九一式手雷 / HUD 图标的绘制，两关与 HUD 共用；3px 粗描边 + 三档平涂 + 卡通高光，杜绝细密写实钢线与半透明水彩。

## 游戏流程

> 按历史时间线推进：**先 1931.9 九一八事变，再 1931.11 嫩江江桥**。东亚大地图会随进度把“当前章节”红图钉自动推进到对应地点。

1. **内容警告** → **标题画面**（`assets/art/title.jpg` 古城墙雪景照片全屏铺底 + 程序化叠层：飘雪粒子 + 灯笼暖光晕 + 暗角 vignette，手绘漫画风菜单）
2. **东亚大地图**（手绘漫画风时间线 Hub：朝鲜半岛 & 台湾地区的殖民标记、1895–1945 日军进军路线、档案纸条；读完源头两张纸条后路线显影，进入按钮按当前章节点亮）。**v3.64 起为两段式**：第一章路线只显影到沈阳 · 九一八事变，江桥地名 / 图钉 / 北上路线不提前出现；九一八通关返回地图后，红图钉才从沈阳沿铁路北上迈向嫩江江桥，行军标记到位后才解锁江桥关卡
3. **纸条档案**（《马关条约》《日韩合并条约》原文、殖民动机、历史代价）
4. **九一八事变 1931.9.18 关卡**（沈阳柳条湖初秋夜 · 可进入/可搜索的叙事场景，4 层视差初秋夜）
5. **嫩江江桥 1931.11.4 关卡**（手绘漫画风横版 2D 关卡，4 层视差雪原战场；九一八通关后地图自动推进到这里，且需等第二段行军标记抵达）
6. **记录档案**：走到阵亡通报 / 史料档案记录点按住 E 约 1.2 秒记录（v3.68 起为可考的**真实烈士与史料档案**，不再用化名口述；逐条出处见 `docs/V368_HISTORICAL_RECORDS.md`）
7. **通关档案** → 史料馆

## 关卡玩法

### 九一八事变 1931.9.18（沈阳柳条湖 — 北大营 — 通信据点）

- **史实场景**：南满铁路一段路轨被炸，日军以此为借口进攻北大营。关卡是初秋夜的旱地与铁路，**没有桥、没有冰封江面、没有江桥式雪原战壕**；中景是北大营营盘（成排营房 + 营门），地面有南满铁路里程碑、路基护坡与柳条湖地名木牌。
- **推进动线**：柳条湖巡道工小屋 → 北大营外民居 → 半塌农户 → 通信据点；逐屋搜集信件、给据点合闸供电，最后发报通关。
- 与嫩江江桥关卡的场景元素逐项对照见 `docs/V367_HISTORICAL_SCENES.md`。

### 嫩江江桥 1931.11.4

- **移动**：A/D 或 ←/→ 左右推进；**空格**跳跃；**S / ↓** 蹲下
- **射击**：鼠标左键（朝鼠标指向开火；立姿据枪 / 跪蹲 / 低姿匍匐按军人条令出专姿立绘）
- **记录**：靠近发光的证词点，**按住 E 约 1.2 秒**（进度环）—— 被敌兵看见时会被打断
- **解谜设计**：档案必须完整记录三份（v3.68 起为**张九洲 / 李英奇 / 张德新**三份真实阵亡通报，缺一不可通关；旧版化名「赵永生 / 李桂兰 / 孙德山」已全部移除）。现场散落的物证碎片（歪把子零件、绷带卷、铁轨碎段）是完整还原档案的关键。九一八关卡则为 5 份：张占元、独立第七旅名录、傅冠军、沈阳公安第六分局「姓名未详」、本庄繁布告。

### 交互机制（嫩江江桥 / 九一八支线通用）

- **敌我 NPC 交战（v3.69 新增）**：关卡里现在有活动的东北军 / 守军友军 NPC（初始 2 名、最多 3 名）。敌兵进入 340px 双方自动举枪交火，压到 74px 就**站定拼刺刀、不再擦肩而过**；双方有 HP、会扣血、会倒地留尸，血量过半会按折扣概率呼叫一次增援。**NPC 互殴的枪击与打斗伤害一律砍半**（步枪 17 / 刺刀 13，原本 34 / 26），支援概率与次数也打折（每方每关最多 2 次、场上敌兵 ≤6 / 友军 ≤3）；玩家两枪击杀敌兵、敌兵对玩家的命中率完全不动，主角体验不被 NPC 抢走。全部数值与极值验算见 `docs/V369_NPC_SKIRMISH.md`。
- **进入房屋 / 探索（v3.67 格局 / v3.68 贴图化 / v3.70 第一视角）**：走到近景民居（残破 / 焚毁）前按 **E** 进屋，**自动切到第一视角**——隐藏走动小人，改画一只可左右扫视的**准星**：用 **A/D** 或 **←/→** 让准星在屋内横向扫视，**准星落到画出来的实体物件**（弹药盒 / 信封 / 遗书 / 手榴弹 / 纱布 / 医药包 / 电闸 / 发信机）上时按 **E** 搜寻 / 查看，长按撬开**宝箱**（约 1.4 秒，60% 开出弹药+手榴弹，40% 冻锁失败）；移到左侧门口按 **E** 离开。住家 / 通信据点 / 焚毁仓库三种格局按房间类型与 `houseId` 播种，不同屋不完全一样。搜索进度自动保存。**v3.68 起背景换成手绘上色漫画风室内贴图**（挂轴 / 方桌 / 砖炉 / 墙面地图 / 发信机），与室外同源；提示牌改成撕边小纸条。**v3.70 起默认第一视角**（准星扫视，不再显示走动小人）。
- **拾取掉枪**：日军阵亡后尸体旁会掉落步枪，靠近按 **E** 拾取——可能枪栓冻死开不了（0 弹），也可能带 2~8 发可用子弹，自动补进弹仓。
- **手榴弹**：按 **G** 投掷木柄手榴弹（抛物线 + 落地反弹 + 2.2 秒引信），范围杀伤靠近的日军；弹仓打空时优先去捡枪或进屋搜弹。
- **沙包掩体**：蹲（S / ↓）或匍匐（Ctrl / C）贴住沙墙即进入「掩体」状态，日军命中率骤降；敌兵会前压逼近。**v3.64 起沙堆落位避开所有房屋门口与占地**，不再挡住进屋动线。
- **手榴弹与爆炸（v3.59–v3.61）**：按 **G** 投掷 M24 木柄手榴弹（抛物线 + 落地横躺 + 2.2 秒引信，方向跟鼠标）；敌兵投九一式手榴弹。爆炸按现实装药建模（65g TNT、重创带 5m≈337px、破片带 8m≈539px，1px≈1.484cm），分四层火光烟尘并让沙包物理飞散；**沙包后仍会受伤扣血**（有掩体 2 心 / 无掩体 3 心），雪地留焦痕。
- **角色状态（v3.61–v3.62）**：玩家残血时移速 ×0.78 并流血；敌兵负伤后 55% 撤退 / 45% 卧倒，不再呆冲；启停加减速平滑，枪口俯仰跟随鼠标高度。
- **野外植被（v3.64）**：草地 / 野地按斑块连续生成，成片草色带 + 密集草丛，不再是「一颗两颗草」。

## 如何运行（小白版，3 步）

1. **装 .NET 8 SDK**（编译 C# 必需）
   到 https://dotnet.microsoft.com/download/dotnet/8.0 下载并安装 .NET 8.0 SDK。

2. **装「.NET 版」Godot 4.7**（注意：不是普通版！）
   到 https://github.com/godotengine/godot-builds/releases 下载 **Godot_v4.7-stable_mono_win64.exe**（文件名带 `mono` 才是 .NET 版）。

3. **打开游戏**
   双击 Godot exe → 点「导入」→ 选择本项目的 `project.godot` → 打开 → 按 **F5** 运行。

> 也可以先在命令行运行 `dotnet build witness.sln` 确认编译通过（0 错误）再进 Godot。

## 给开发者的提示

- **美术风格红线（用户 2026-11-12 定调）**：全作品只用「手绘上色漫画风」，程序化绘制一律走 `InkStyle.cs` / `MangaPropArt.cs` / `InteriorExplore.cs`；不要用钢笔淡彩、写实渲染或细密钢笔画。AI 生成贴图的候选图先放 `tools/bridge_restyle/previews/` 给用户过目确认后才可覆盖仓库
- **室内格局红线（用户 2026-11-12 二次强调）**：进屋必须是「玩家能走进去、能走动、能寻找画出来的实体物件」的房间，**不是**「背景 + 一排文字标签按钮」的清单式 UI；新增房间一律复用 `InteriorExplore.cs`，不要再各自堆 `Button`
- **场景美术红线（用户 2026-11-12 定调）**：营房 / 铁轨等大件一律走 `MangaSceneArt.cs` 的手绘漫画风贴图，不许再用 `DrawRect` 方块 + 等距小矩形拼「建筑 / 轨道」；贴图缺失的兜底也必须有手绘抖动笔触。新增候选图先放 `tools/bridge_restyle/previews/` 给人过目，AI 生成图必须标注需人工精修与合规确认
- **NPC 交战红线（用户 2026-11-12 定调）**：敌我 NPC 不许擦肩而过，进入 340px 自动交火、74px 站定拼刺刀；**NPC 互殴伤害一律 ×0.5**、支援概率与次数必须打折，玩家侧数值不许被连带改动。所有常量只在 `SkirmishRules` 维护，数值与极值验算同步写进 `docs/V369_NPC_SKIRMISH.md`
- **记录呈现红线（用户 2026-11-12 定调）**记录 / 档案不许用米黄 UI 对话格子，一律走 `BurntPaperArt.cs` 的烧毁纸张；不许给真实烈士编造家书、遗言或化名，姓名与出处只在 `scripts/MartyrArchive.cs` + `docs/V368_HISTORICAL_RECORDS.md` 两处维护，不许散改到各关卡脚本
- **史实场景红线**：新增关卡前先查 `docs/V367_HISTORICAL_SCENES.md`；历史上没有的地标（如九一八现场的桥）不要画蛇添足，也不许把上一关的大件直接复制过去
- **C# 脚本文件名必须与类名大小写完全一致**，否则 Godot 会静默跳过注册
- `project.godot` 必须显式写 `[dotnet] project/assembly_name="witness"`，否则报「DLL 找不到」
- 自动截图巡游：开发时把 `scripts/Capture.cs`（或旧 `scripts/VerifyTour.cs`）临时挂到 `[autoload]` 再正常运行游戏，跑完自动退出并输出到 `docs/screenshots/`；**push 前必须移除**
- headless 测试：`Godot_v4.7-stable_mono_win64.exe --headless --path . --script res://tests/SmokeTest.cs`
- 背景贴图管线：AI 图生图生成 → `_gen/backdrop/process.py` 去白底抠图 + 紧裁 + 水印条 → 落 `assets/art/backdrop/` 并让 Godot 生成 `.import`
- **刷新 README 画廊的标准流程（v3.64 起）**：改过贴图先 `--headless --import --path .` 重新导入；再跑 `Godot_v4.7.2-stable_mono_win64_console.exe --path . --rendering-driver opengl3 --resolution 1280x720 scenes/Capture.tscn`（另有 `CaptureN918` / `CaptureMap` / `CaptureRoom` / `CapturePaper`），真帧落在项目根 `_shots/`（已 gitignore）→ 映射进 `docs/screenshots/` → **bump README `?v=` 版本号 +1** → 提交并推送 `nakamura85`。headless 主视口 dummy 渲染器读不到纹理，必须靠 `SubViewport` + `opengl3` 才能出真图；`triangulation failed` 是前景雪檐的历史无害警告。
