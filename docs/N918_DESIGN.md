# 九一八事变关卡 · 设计规格文档（N918）

> **版本**：v0.1（设计稿，非破坏性产出，不改代码）
> **作者**：创意总监 · 游有方
> **关联关**：前接「东亚大地图」，后接「嫩江江桥 1931.11.4」（流程顺序：地图 → 九一八 → 江桥 → …）
> **上游已确认约束**：玩家身份固定为**东北军通信兵**；完成机制统一为「收集信 → 进屋找发信机 → 操作发报 = 通关」，同时套用九一八与江桥两关；美术复用江桥 manga 手绘管线，不提需大量新美术资产的玩法；江桥核心实现（战斗/视差/昼夜）不许重构，九一八只做轻量兄弟版。
> **伦理红线（项目铁律）**：在世真实人物一律不用真名，角色用复合虚构；九一八所涉历史人物（张学良、荣臻等）如需出场，仅作背景旁白/代称（「上峰」「长官」），不捏造具体对话。
> **用户红线**：参数均为「建议值」，最终以主程序实现为准。

## 0. 核心玩法复述（确认用，5 行）

1. **一句话定位**：你是东北军通信兵，1931.9.18 夜的沈阳，在柳条湖爆炸与北大营陷落之间，收集散落的家书与阵亡者口信，最终潜入电报据点用无线电把消息发出去。
2. **怎么操作**：A/D 移动 · S 蹲下潜行 · 鼠标左键射击 · E 互动/记录/进屋 · 屋内面板点击或长按操作发信机。
3. **一局怎么玩**：探索区段 → 搜屋/拾尸收集信 → 接到「不抵抗令」做抉择 → 进电报据点屋 → 操作发信机发报 = 通关。
4. **赢的条件**：集齐 ≥3 封信 + 满足发信机前置（若启用供电解谜则需通电）→ 屋内长按 E 完成发报。
5. **一句话亮点**：以「记录与传递」的通信兵视角，亲历不抵抗之夜的无力与见证。

> 情绪基调：**悲怆、压抑、克制**。全程不煽情、不血浆；用「来不及、传不出去、城已经没了」的静默损失感替代爆点。通信兵视角 = 你是旁观者+记录者，不是扭转战局的人——这正是悲剧核心。

## 1. 一句话定位与情绪基调

**定位**：横版 2D 手绘漫画风，以「东北军通信兵」第一人称视角重走 1931.9.18 沈阳之夜。玩法内核是**记录与传递**——你不是来打仗的（上峰令你不准抵抗），你是来「把发生的事送出去」的。

**情绪基调**（给美术/音频/文案统一参照）：
- **悲怆**：家园在脚下沦陷，而你不能还手。
- **压抑**：夜色、初秋微雪、被炸断的铁轨、空荡的营房、此起彼伏又渐弱的枪声。
- **克制**：没有大字报式控诉，没有血腥特写；损失用「沉默的留白」呈现（参照江桥 `EvidencePoint` 被销毁时只画一道墨叉的处理）。
- **通信兵专属质感**：电报纸、摩尔斯、电流声、发不出的焦虑——「把消息送出去」是这关最有历史重量的动词。

## 2. 核心循环（探索 → 收集信 → 抉择 → 进屋发信 = 通关）

```
[起点：柳条湖外·夜] → 探索区段（见 §3）
   ├─ 屋内搜刮 spot（letter 类）→ 拾得信
   ├─ 阵亡者/证言点（世界纸页）→ 拾得信
   ├─ 柳条湖爆破点（见证，不卡关）
   ├─ 接到「不抵抗令」→ 遵令/违令 抉择（无 Game Over，只改结局文案）
   └─ 电报局搜救（可选前置：找零件/合闸通电）
        ↓
[进电报据点屋] → 屋内面板出现「无线电发信机」spot
   ├─ 信 < 3 或无电 → 提示缺什么，不推进
   └─ 信 ≥ 3 且通电位 → 长按 E 发报（进度环满）
        ↓
[触发通关] → LevelEndUi（史实结果 + 后续章节提示）→ N918Done=true → 存档 → 进入江桥
```

**3–5 行说明**：
- 玩家沿横版从西（柳条湖）向东（沈阳城/电报据点）推进，沿途在屋内与阵亡者处收集「信」。
- 中段接到「不抵抗令」做一次道德/历史抉择，两种选择都不通关失败，只改变闭卡文案与少量状态。
- 终点是「电报据点」屋：屋内找到无线电发信机，集齐 ≥3 封信且满足前置后长按 E 发报即通关。
- 全程可选战斗（日军巡逻/遭遇），但战斗不是通关条件，弹药经济与江桥一致（不够就进屋搜、拾尸捡枪）。
- 通关门禁 = 江桥同款「发信机提交」，两关共用一套交互契约（见 §4.6）。

## 3. 场景结构（横版 2D · 区段 / 地标）

**世界尺寸（建议值）**：WorldW ≈ 3800–4200px（江桥约 5000px，本关更紧凑，契合「轻量兄弟版」）。地面顶面 y 沿用江桥 `GroundY` 常量，视差/昼夜系统直接复用。

## 4. 信与发信机机制详细设计

### 4.1 信的获取（两类来源，统一进 `N918Letters`）

- **A. 屋内搜刮 spot**：复用 `HouseInteriorUi` 现有 `letter` 类 spot（EnterableHouse.cs 中 `AddSpot("letter1","压在灶台下的信","letter",…)` 已存在）。点开即把信 id 加入 `N918Letters`，并弹 `FieldNoteUi` 展示信的内容（复合虚构家书，参照江桥 `letter`/`will` 的写法，附「人物为复合虚构」注）。
- **B. 阵亡者 / 证言点（世界纸页）**：在北大营等区段放置「纸页」拾取点，复用 `EvidencePoint`/`Testimony` 的视觉与「走近发光 + 长按 E 记录」交互（`RecordRing` 进度环）。记录完成 → 信 id 加入 `N918Letters`。文案为阵亡者口信（复合虚构，不署名真实人物）。
- 两类来源**可混合**计入通关所需的 ≥3 封；来源比例不强制（玩家可全靠搜屋，也可靠拾尸/证言）。

### 4.2 是否需要多封

**需要多封**。建议：**3 封必需 + 1–2 封可选**。
- 必需 3 封是通关硬门槛（与江桥「3 段证言」对齐，统一门禁）。
- 可选 1–2 封藏在难搜点（如烧毁屋、远角），集满影响闭卡文案细节（如「你带出了全部 5 封信」），但**不卡通关**。

### 4.3 发信机 spot 在屋内的呈现

- 发信机是**电报据点屋内面板中的一个特殊 spot**，类型建议新增 `transmitter`（在 `HouseInteriorUi` 的 spot 体系内，与现有 `chest` 同级）。
- 视觉：屋内面板里一张标注「无线电发信机」的纸片/按钮（与 `letter`/`chest` 同款 chip 样式，**无新美术资产**）；屋外同步放 `telcrate.png` 作世界地标，让玩家从外面就能认出「这是电报据点」。
- 该 spot 始终可点击；能否真正发报由前置判定（§4.4）决定。

### 4.4 操作发信机提交的交互（按键 / 长按 / 判定）

- **触发**：在屋内面板点击「无线电发信机」spot（或屋外世界空间对准 telcrate 长按 E——二选一，建议优先屋内面板点击，与江桥屋内逻辑一致）。
- **前置判定** `level.CanTransmit()`：
  - `N918Letters.Count >= 3` 为真；
  - 若启用 §5.3 供电解谜，则 `N918Powered == true`。
- **不达标**：弹 HUD 提示（如「信件未齐 X/3，先去收集」或「发信机没电，先恢复供电」），spot 不推进、不标记完成。
- **达标**：进入**长按发报**——复用 `HouseInteriorUi` 中 `chest` 已有的「长按进度」代码路径（`_prying`/`_pryT`，约 1.4–2.0s 建议值），面板中央显示 `RecordRing` 式进度环；中途松手则进度归零需重来。
- **进度满**：调用 `level.OnTransmitted()`。

### 4.5 提交后触发通关

`OnTransmitted()`：
1. 设 `GameState.I.S.N918Done = true`；
2. 写入 `N918Letters`/`N918Resist`/`N918Visited`/`N918Powered` 等；`GameState.I.Save()`；
3. `Player.ControlLocked = true`，淡出黑幕（建议 0.6–0.65 透明度，与江桥一致）；
4. 弹出 `LevelEndUi`（九一八版）：史实结果（沈阳/辽宁吉林陷落、不抵抗令、数月后伪满成立）+ 玩家表现（带出几封信、抉择分支、是否护送难民）+ 后续章节提示 + 「返回地图 / 重玩」。

### 4.6 与江桥「记录 3 段证言 → 发信机提交」的统一门禁

两关共用**同一套「发信机提交」交互契约**，仅 `CanTransmit()` 的前置表达式与闭卡文案不同：

| 维度 | 九一八（本关） | 嫩江江桥（既有，需小改） |
|---|---|---|
| 通关前置 | `N918Letters.Count >= 3` (+ 通电) | `JiangqiaoTestimony.Count >= 3` |
| 发信机交互 | 屋内 `transmitter` spot，长按发报 | 同左（改造现有 `CheckEnding`） |
| 闭卡文案 | 沈阳沦陷 / 不抵抗令 / 信数 | 江桥十六天 / 三份口述 |
| 通关回调 | `N918Done=true` → 进江桥 | `JiangqiaoDone=true`（保持） |

**江桥需小改**：把 `JiangqiaoLevel.CheckEnding()` 里「走到 x≥4780 且证言≥3 即通关」改为「在电报据点屋内操作 `transmitter` spot 通关」——证言记录（t1/t2/t3）完全保留不动，只把最终「送出」换成「进屋发信机提交」。这样两关在玩家体感上**同一套完成门禁**。

### 4.7 完成条件清单（玩家必须做的步骤）

1. 在关内收集 **≥3 封「信」**（`N918Letters.Count >= 3`）；来源可混合（屋内 spot + 阵亡者/证言点）。
2. 找到并进入「**电报据点**」屋，屋内存在发信机 spot。
3. （若启用 §5.3）满足发信机前置：**通电 / 有零件**（`N918Powered == true`）。
4. 在发信机 spot **长按 E 完成发报**（进度环到 100%）。
5. 上述全满足 → 触发 `LevelEndUi` → `N918Done=true` → 存档 → 解锁/进入江桥。

**反条件（用于 §8 QA）**：未进屋操作发信机 → 不通关；信 <3 时操作 → 提示缺信且不推进；发报中途松手 → 进度归零需重来。

## 5. 史实玩法扩展（选 4 项落地设计）

> 用户希望更丰富。以下 4 项全部给出落地设计；按主题契合度排序，**①②③④ 均建议纳入**，其中 ③ 明确标为「可选 / 可砍」以守范围。每项均标「是否需要新资产」。

### 5.1 ① 不抵抗令悲剧抉择（核心，强烈建议）

- **机制**：玩家推进至北大营/接到急电时，触发 `DialogueUi.ShowChoice`（江桥 `Level.cs:717` 已用此 API，零新代码）。旁白以**代称**呈现命令——「上峰急电：避免冲突，原地待命，不准抵抗」，不出现张学良等真实人物姓名、不捏造对话。
  - 选项 A「遵令 · 收起武器，退入民居」：不进入战斗，弹药与生命保全，但闭卡文案强调「你服从了，城照常丢了」。
  - 选项 B「违令 · 还击」：触发与日军的小股遭遇战（复用江桥战斗/弹药经济），可造成伤亡、消耗弹药，但**历史结果不变**——沈阳仍陷落。
- **反馈**：两种选择各自写入 `N918Resist`（1=遵令 / 2=违令）；闭卡文案呈现**两种不同变体**（QA 必须能分别触发，见 §8）。无 Game Over、无强制失败。
- **与核心循环衔接**：抉择发生在「收集信」中段，不改变通关门槛；只改文案与少量状态（违令会多耗弹药，间接提高后续「弹不够要搜」的张力）。
- **新资产**：无（纯 `DialogueUi` + 文案）。

### 5.2 ② 柳条湖爆破点还原（核心，强烈建议）

- **机制**：区段①放置被炸断的南满铁路铁轨（`crater.png` 弹坑 + 程序绘制断轨），玩家走近出现史料纸条（`FieldNoteUi`，写法同江桥 `clue`：「柳条湖段路轨被炸，关东军反诬……」），看完即「见证」，记入 `N918Visited`。
- **反馈**：克制呈现——断轨、雪夜、纸条；不演爆炸动画。闭卡文案据 `N918Visited` 是否含柳条湖，追加一句「你亲眼看见了被炸毁的铁轨」。
- **与核心循环衔接**：纯叙事见证点，**不卡通关**，是情绪与史实的锚。
- **新资产**：无（crater 已在 props；铁轨可用现有 `rail` 绘制思路或程序线）。

### 5.3 ④ 电报局搜救（小解谜，建议纳入，给「进屋找发信机」真实重量）

- **机制（轻量版，1–2 步）**：电报据点的发信机初始「无电/缺零件」。
  - 子目标 a「找零件」：在侧屋 `HouseInteriorUi` 里放一个 `clue`/`letter` 类 spot「发信机真空管/电池」，拾得即 `N918Powered` 置位（同 spot 体系，无新资产）；
  - 子目标 b「合闸通电」：在电报据点屋外/内放一个**长按 E 合闸**交互（复用江桥 `valve`/`bolt` 的「对准长按」模式，约 1.2s）。
  - 两者满足后，发信机 spot 才可被操作（§4.4 前置）。
- **反馈**：未通电时操作发信机 → 提示「发信机没电，先恢复供电」；通电瞬间屋内一盏灯/指示灯亮（程序绘制，无新资产）。
- **与核心循环衔接**：直接将「进屋找发信机」变成「先让发信机可用再发报」，强化通信兵「把消息送出去」的主题，且**仍汇入同一通关门禁**。
- **新资产**：无（零件用现有 spot chip；合闸复用 valve/bolt 交互；指示灯程序绘制）。若美术希望更具体，可后续由美术总监加一个小型发信机贴图，但非必需。

### 5.4 ③ 难民护送 / 帮助（简化 · 可选 / 可砍）

- **机制**：复用 `Refugee.cs`（南京关已验证）。关卡内放 **2–3 名**难民（needs: food/blanket），头顶需求徽记（碗/毯，沿用 `Refugee._Draw` 的 `FadedRed` 徽记）。玩家可给物资（复用江桥物资 economy 思路）或简单护送至安全点。
- **反馈**：帮助数计入 `N918Refugees`，闭卡文案「你护送了 N 名乡亲撤出沈阳城」。
- **与核心循环衔接**：纯可选支线，不影响通关门槛；守「九一八简化」原则，不做南京那套深度交互。
- **新资产**：无（复用 `Refugee.cs` 与精灵）。
- **范围提示**：若工期紧，本项**可砍**而不影响核心循环与通关。

## 8. 验收标准（QA 用 · 可独立复算的通过条件）

1. **不通关条件**：未进入电报据点屋、未操作发信机 → 关卡不结束（`N918Done` 保持 false，`LevelEndUi` 不出现）。
2. **信不足不发报**：`N918Letters.Count < 3` 时操作发信机 → 不触发通关，HUD 提示「信件未齐 X/3」，发信机 spot 保持可操作但不推进。
3. **完整通关**：`N918Letters.Count >= 3` 且前置满足（若启用④则 `N918Powered==true`）→ 长按 E 发报完成 → 触发 `LevelEndUi`、`N918Done=true`、存档写入、地图「进入江桥」按钮出现。
4. **双结局文案存在**：不抵抗抉择两种闭卡文案（遵令/违令）在代码中均存在且可触发；QA 可经存档注入 `N918Resist=1` 与 `N918Resist=2` 两种状态，分别验证面板文案不同。
5. **无脚本报错**：场景内无任何运行时报错/空引用；发信机 spot 在屋内面板可点击；`telcrate.png` 正常加载；`crater.png` 柳条湖正常显示。
6. **重玩重置**：重玩本关时 `N918Letters`/`N918Loot` 重置，可再次正常通关。
7. **难民（若启用③）**：帮助数正确计入闭卡文案；若未启用，闭卡文案不引用难民。
8. **无 Game Over 路径**：任何失败（中弹、被巡逻发现、违令还击、抉择）仅造成损失，不触发强制重开。
9. **与江桥一致**：江桥改造后，其「记录 3 段证言 → 屋内发信机提交」门禁与本关「收集 3 信 → 屋内发信机提交」体感一致（同款交互契约）。

## 9. 风险与可砍项

- **⚠ 基调冲突（重要）**：江桥 `PUZZLE_DESIGN.md` 与 `JiangqiaoLevel` 中存在「被发现 5 次 → Game Over → 重开」逻辑，与项目铁律「**没有 Game Over 只有损失**」相悖。九一八严格遵循「无 Game Over 只损失」；建议在为江桥接入发信机门禁时**一并移除江桥的 Game Over 分支**，使两关基调统一。此为跨关一致性风险，需主程序/主理人确认。
- **伦理红线**：所有人物复合虚构；「不抵抗令」只以代称（上峰/长官）旁白呈现，**不得**为张学良、荣臻等真实人物编写具体对话或署名台词。闭卡/纸条须保留「人物为复合虚构，不对应单一在世者」注。
- **范围守门**：九一八只做轻量兄弟版；若工期紧，优先保「核心循环 + 发信机门禁 + 不抵抗令抉择 + 柳条湖见证」，④供电解谜与③难民为**可砍**项，砍后仍可独立通关。
- **集成风险**：本关需 `Main`/`AsiaMap` 配合把流程改为「地图 → 九一八 → 江桥」，属必要小改（见 §6）；否则九一八仍只是弹窗。
- **季节切换**：当前按「初秋微雪」设计；若用户后选「深冬」，仅调色板与雪量变化，结构与玩法不变。

## 10. 历史内核一句话总结

**九一八不是「我们输了」的故事，而是「上面的命令让你不能还手、而你唯一能做的，是把这片土地正在失去的事实记录下来、送出去」——这关要传达的，正是不抵抗之夜中一个通信兵关于「见证」的悲怆重量。**
