## 三、数值表（可复算）

统一入口：`scripts/NpcSkirmish.cs` → `SkirmishRules`。所有常量集中在这一处，不散改到关卡脚本。

| 变量 | 值 | 单位 | 取值范围 / 说明 |
|------|-----|------|-----------------|
| `NpcHp` | 100 | HP | 双方 NPC 共用，>0 |
| `DamageScale` | 0.5 | — | **用户要求「砍半」**，只作用于 NPC↔NPC |
| `RifleDamageBase` | 34 | HP/发 | 未打折基准（仅供对照，玩家数值不走这里） |
| `MeleeDamageBase` | 26 | HP/刀 | 未打折基准 |
| `RifleDamage` | 17 | HP/发 | 34 × 0.5 |
| `MeleeDamage` | 13 | HP/刀 | 26 × 0.5 |
| `MeleeRange` | 74 | px | 进入即停住拼刺刀 |
| `FireRange` | 340 | px | 进入即自动交火 |
| `FireInterval` | 2.6 | s | ±0.3~0.5 随机；比玩家慢 |
| `MeleeInterval` | 1.5 | s | 双方各自计时 |
| `EnemyDistractRange` | 240 | px | 敌兵开始分心还击的距离 |
| `EnemyDistractInterval` | 3.4 | s | 分心还击间隔 |
| `EnemyHitChance` | 0.70 | — | NPC 之间不是每枪必中 |
| `ReinforceChanceEnemy` | 0.25 | — | **打折**：不是每次呼叫都来 |
| `ReinforceChanceAlly` | 0.15 | — | 友军折扣更低 |
| `MaxReinforcePerSide` | 2 | 次/关 | 每方硬上限 |
| `MaxEnemiesOnField` | 6 | 人 | 场上硬上限 |
| `MaxAlliesOnField` | 3 | 人 | 场上硬上限 |

### 极值验算

1. **步枪最快倒地**：`ceil(100 / 17) = 6` 发。全中间隔 5 × 2.6 = **13.0s**；按 0.70 命中率的期望发数 `6 / 0.70 ≈ 8.6` 发 → **约 22.3s**。
2. **刺刀最快倒地**：`ceil(100 / 13) = 8` 刀，间隔 1.5s → **10.5s**（双方同时计时，先手差 ≤1.5s）。
3. **支援极值**：初始友军 2 名 + 最多 2 次增援（但场上限 3）→ **场上友军 ≤3**；敌兵每波 1–3 名 + 最多 2 次增援（场上限 6）→ **场上敌兵 ≤6**。最坏情况玩家仍需面对 6 名敌人，主角戏份没被 NPC 抢走。
4. **玩家侧不变**：玩家对敌兵仍是「两枪阵亡」（`Hit()` 原逻辑），敌兵对玩家命中率仍是 0.28 / 0.10 / 0.00。**砍半只作用于 NPC 互殴**。

## 五、如实标注的差距（不吹）

- 两张新贴图是 AI 生成后裁掉右下角生成水印、抠掉浅灰棋盘格 / 白底、统一尺寸接入；候选原图留档在 `tools/bridge_restyle/previews/v369/`，**需人工精修与合规确认**。营房挂轴 / 门匾为无字木板（刻意不生成伪文字），旗杆三角旗是示意绘制；铁轨的铆钉与枕木间距是合理复原，非 1931 年南满铁路工程图。
- 贴图平铺仍有重复周期（288px 一段）；用交替镜像 + 6px 重叠打散，但没有做逐像素无缝拼接。
- 江桥 `DrawMidLandmark()` 的守军土垒 / 旗杆仍是程序化几何，本轮只按用户点名的两处（营房 / 铁轨）改贴图，避免两关又被改成一样。
- 关卡代码层仍是同构的两个 `.cs`；`NpcSkirmish.cs` 用 `partial class` 给两关各写一份战场接线，尚未抽成共享基类 + 关卡数据。
- 友军 AI 是「站定交火 / 贴身搏斗」两态，没有掩体利用、包抄、撤离等战术；这是刻意的——用户要求「不要抢主角游玩体验」。
